# 2026-06-22 Codex 小红书系列标题方向

用户想做一个「你不知道的 Codex」系列，主要发布 Codex 能做的事情。

判断：栏目名可以保留「你不知道的 Codex」，但单篇标题不宜只写功能点。小红书更适合用「具体任务 + 可见结果」作为标题主结构，让读者先看到 Codex 能替自己完成什么，再在内容里解释能力边界。

推荐栏目包装：

- 你不知道的 Codex
- Codex 还能这么用
- 把 Codex 当同事用
- Codex 实战日记
- Codex 的 100 种用法

推荐合集简介：

> 记录 Codex 在真实工作里的用法：读项目、改代码、跑测试、查资料、写方案、整理文件、处理重复任务。这里不讲抽象的 AI 概念，只看它能怎么接手一件具体的事，以及结果到底好不好用。

推荐标题模板：

- 你不知道的 Codex 01｜让它读完整个项目再改代码
- 你不知道的 Codex 02｜让它自己跑测试、看报错、修问题
- 你不知道的 Codex 03｜把一个想法变成可运行网页
- 你不知道的 Codex 04｜让它帮你整理一整个文件夹
- 你不知道的 Codex 05｜让它接手一次代码 review

长期定位：少讲「AI 很强」，多展示「我把一件具体工作交给 Codex，它具体做了哪些步骤，最后产出了什么」。
