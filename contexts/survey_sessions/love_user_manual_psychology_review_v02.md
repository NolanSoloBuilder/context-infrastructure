# 「你的恋爱使用说明书」心理学审查 v0.2

日期：2026-07-22  
审查方式：理论与已发表研究的结构化桌面审查  
结论等级：可以作为关系场景中的自我观察工具；不能称为经过信效度验证的心理测验

## 结论先说

原方案的方向可以保留，但产品名称和计算方式需要降一点“心理测试感”。

保留四个观察角度：

1. 冲突时先靠近，还是先自己缓一缓。
2. 先观察整理，还是直接说出来。
3. 容许变化，还是更需要明确安排。
4. 等状态稳定，还是主动发起修复。

这四个角度能从依恋、伴侣回应、情绪调节、冲突沟通和关系修复研究中找到理论支点，但它们不是一个已经发表并验证过的统一四因素量表。因此，产品应该叫“关系反应自我观察”，结果应该叫“这次回答里最明显的倾向”，不能叫“人格类型”“依恋类型”或“专业心理测验”。

## 理论审查

### 1. 靠近与独处：有理论支点，但不能偷换成依恋类型

成人依恋研究常用连续维度，而不是把所有人硬分成几个互斥类型。Fraley 对 ECR-R 的说明以及相关测量研究都强调连续维度建模；其公开说明也指出，依恋差异更适合按程度理解，而不是按种类理解。

本产品只观察冲突后的调节偏好：用户更容易借助连接恢复，还是先通过自己的节奏恢复。它不测量完整的依恋焦虑或依恋回避，也不复用 ECR-R 题目。

决策：

- 保留该维度，但改名为“恢复方式”。
- 两端写成“先靠近—先独处”，不写“焦虑—回避”。
- 不把高分解释成黏人，也不把低分解释成冷漠。

参考：[Fraley 的 ECR-R 说明](https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr.htm)、[依恋维度说明](https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr-oldernorms.htm)、[ECR-RS 研究摘要](https://pubmed.ncbi.nlm.nih.gov/21443364/)

### 2. 直接表达与先观察：有沟通研究支点，但不是能力排名

需求—退缩模式研究表明，冲突中的追问、批评、退缩和防御会形成相互影响的互动，而不是一个人的单方面性格。后续研究也发现，冲突中压抑表达与较差的问题解决存在关联，但具体行为会受到被重视感、情境和伴侣反应影响。

这意味着“直接说”不能简单等于成熟，“暂时不说”也不能简单等于逃避。应该观察的是用户在什么条件下愿意说，以及是否能给出可理解的信息。

决策：

- 改名为“表达节奏”。
- 两端写成“先观察—直接说”。
- 题目不再把沉默、语气或等待写成明显的坏答案。

参考：[Christensen 与 Heavey 的需求—退缩研究](https://pubmed.ncbi.nlm.nih.gov/2213491/)、[冲突中的表达压抑与解决研究](https://pubmed.ncbi.nlm.nih.gov/29927283/)

### 3. 弹性与明确：更适合叫场景偏好，不适合包装成稳定人格

伴侣回应研究把“被理解、被重视、被关心”视为亲密关系中的重要过程，也有中文伴侣回应量表的本土研究。但“需要多明确的安排”本身不是一个等同于伴侣回应的成熟独立构念，它还会受事件严重度、关系阶段、双方承诺和生活环境影响。

决策：

- 把“确定性需求”改成“信息偏好”。
- 两端写成“容许变化—需要明确”。
- 不给这一维设置好坏，也不把高分写成控制。
- 报告必须提醒：当关系本身不稳定时，高明确需求可能是情境反应，不一定是长期倾向。

参考：[伴侣回应理论综述](https://sas.rochester.edu/psy/people/faculty/reis_harry/assets/pdf/ReisClarkHolmes_2004.pdf)、[中文伴侣回应量表研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9208143/)、[伴侣回应与长期幸福感研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5458635/)

### 4. 等待与主动修复：可以观察行为倾向，不能推断谁更爱

冲突后的恢复、重新建立积极互动和主动修复都出现在关系研究中；但主动发起不必然更健康，等待也不必然意味着放弃。修复是否有效取决于时机、对方是否回应、冲突严重度以及安全边界。

决策：

- 改名为“重启方式”。
- 两端写成“等状态稳定—主动重启”。
- 高分不写成“更负责”，低分不写成“更冷淡”。
- 暴力、威胁、跟踪、强迫控制等场景不适用普通修复建议。

参考：[婚姻冲突后的恢复研究](https://pubmed.ncbi.nlm.nih.gov/10526766/)、[关系中的自主与联结研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7057354/)

## 对原题库的修改

### 删除否定式反向题

原题库混入了“我通常不需要……”“我不会……”一类否定式反向题。研究长期提示，反向措辞可能制造独立的方法效应，反向计分不等于消除了理解负担。

新版不用同意/不同意量表，而是每题给出五个具体反应。两端都写成可以理解的选择，中间允许“看情况”。部分题目的计分方向可以反转，但文字本身不使用绕口的否定句。

参考：[反向题的 IRT 方法效应研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5965508/)、[婚姻质量量表中的反向措辞研究](https://openpsychologyjournal.com/contents/volumes/V15/e187435012208150/e187435012208150.pdf)

### 删除社会赞许答案

原题目中“我会把希望你怎么做说得具体”“我愿意换一种方式再尝试”太像正确答案。新版把两端都写成现实中可能有功能的策略，例如“先自己想清楚再开口”与“边想边说，让对方一起理解”。这不能完全消除社会赞许偏差，但至少不再提示用户选择“更成熟”的答案。

### 删除假精确分型

原版用人为设定的八个四维中心计算欧氏距离。没有样本和聚类证据时，这会让结果显得比证据更精确。

新版规则：

- 四个维度仍输出 0–100，仅表示题目选项的平均位置。
- 结果名只取离中点最远的一个维度方向，共八种“阅读入口”。
- 结果页同时展示四个连续维度，结果名不能覆盖真实分数。
- 不显示百分位、不写“超过多少人”、不声称准确率。

## 新版八个结果入口

| 最明显方向 | 结果名 | 不是在说什么 |
|---|---|---|
| 更靠近 | 回应确认 | 不是黏人 |
| 更独处 | 独处复原 | 不是冷漠 |
| 更直接说 | 清晰开口 | 不是更成熟 |
| 更先观察 | 谨慎开口 | 不是不会沟通 |
| 更需要明确 | 秩序确认 | 不是控制欲强 |
| 更容许变化 | 弹性相处 | 不是不认真 |
| 更主动重启 | 主动修复 | 不是更爱 |
| 更等待稳定 | 慢热重启 | 不是放弃关系 |

如果最明显方向离中点不足 8 分，结果页仍给出最接近的入口，但明确标注“倾向较轻，具体场景影响更大”。

## 可以宣称与不能宣称

可以：

- “帮你整理最近半年在关系冲突中的常见反应。”
- “结果是一份自我观察，不是人格结论。”
- “四个方向来自关系与沟通研究中的相关问题，但本问卷不是已有量表的替代品。”

不能：

- “测出你的真实依恋类型。”
- “心理学认证、专业量表、科学准确率 95%。”
- “根据结果判断对方适不适合你。”
- “你的原生家庭导致了这种人格。”

## 不做访谈后的替代校验

用户明确不做访谈，因此本轮采用以下可完成检查：

1. 构念与研究概念逐项对照。
2. 每题只测一个主要判断，不混合两个行为。
3. 删除否定式反向措辞与明显正确答案。
4. 检查四个维度各有六个不同场景，避免同义重复。
5. 检查结果解释没有病理化、因果化或关系决策建议。
6. 用自动化测试验证计分方向、边界分数、结果映射与答题流程。

这套校验能提高内容合理性和软件正确性，但不能产生统计信度、结构效度、重测稳定性或人群常模。除非未来收集真实样本，否则产品应长期保持“自我观察工具”的定位。
