# MVP 交付范围与实现合同

2026-09-10 用户已授权继续细化与实施，任务持续到高标准 MVP 验收后结束。此前“本轮仅设计”属于历史阶段，不再是应用实现禁令。总目标仍为通用金融研究 Agent 与字段级证据产品。

## MVP 的用户结果

用户在真实工作区提出研究问题，Agent 可自主检索、精读、计算和写作；可生成短核验与完整财报分析，也能做至少两个来源的证据比较。报告能打开原文并定位字段，派生指标能查看输入和公式；刷新恢复同一任务，后续研究形成新版本。模板依据用户请求，而不是固定财务维度流程。

本次不以静态样稿、fake工具调用、离线测试或只保存一个数字替代上述结果。六类模板可作为内置方法集合，真实验收优先覆盖短核验、财报分析和跨来源比较；估值等模板如缺数据需要明确缺口，不编数。

## 当前架构决策

- 先使用已安装且可核对类型的 Pi 0.85.1 核心循环做运行适配，模型和工具经 JSONL 交给 Python 宿主执行。
- 不复用个人 Pi 登录配置。模型身份、model-policy、预算和工具授权继续由服务管理。
- 首批工具全部由宿主提供，没有隐式的主机 shell 或任意网络权限。计算与研究文件通过有范围的工具实现；未来通用代码沙箱单独接入执行隔离。
- Pi管理工具循环；Python管理外部服务和持久化；Backend管理最终任务和报告版本。不能又在Python重写一套模型决策循环。
- 新研究报告协议与旧 financial-report/v1 明确区分；不伪造旧三Gate凭据。旧报告继续用原renderer和resolver读取。
