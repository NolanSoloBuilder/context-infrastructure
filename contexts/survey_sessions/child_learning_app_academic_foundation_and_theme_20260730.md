# 儿童游戏化学习 App：学术基础与首发主题

日期：2026-07-30  
目标年龄：6–8 岁  
产品阶段：概念收敛与 MVP 学习模型设计

## 结论

首发主题建议定为：

> **《小小修复师：会呼吸的水岛》**  
> 孩子通过观察、预测、搭建和反复实验，恢复岛屿的水路，让农田、村庄、湿地和机械重新运转。

这个主题不是为了选择一个容易画的故事皮肤，而是因为水路系统天然承载四种可观察的学习行为：

1. 理解物体、路径和位置之间的空间关系；
2. 旋转、组合与变换部件；
3. 预测改变一个部件会怎样影响整个系统；
4. 根据反馈修改方案，而不是随机试错。

产品首版不要声称训练笼统的“智力”“科学素养”或“系统思维”。可验证的第一主张应该收窄为：

> 经过一组由易到难的水路修复任务，6–8 岁儿童能更有计划地处理空间路径、部件旋转与简单因果系统问题，并能把策略迁移到未见过的新地图。

这仍然是待验证的产品假设，不是现成的科学结论。

## 为什么选择空间推理作为第一能力

空间能力有相对扎实的可训练证据，而且与 6–8 岁的触屏操作天然匹配。

Uttal 等人对 217 项研究的元分析显示，空间训练相对控制组的平均效应量为 Hedges's g = 0.47，并讨论了效果的持久性与可迁移性。[Uttal et al., 2013](https://doi.org/10.1037/a0028446)

针对 0–8 岁儿童的后续元分析纳入 20 项干预研究、1535 名儿童，报告训练相对控制组的平均效应量为 g = 0.96；其中包含游戏、动手操作、课堂课程和具体空间任务。不过该研究也明确指出研究数量较少、效应异质性较大，而且没有纳入对未训练任务迁移效果的分析。因此它支持“值得训练”，不能直接证明某个 App 一定有效。[Yang et al., 2020](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2020.01938/pdf)

这决定了产品策略：

- 第一版训练对象应具体到空间关系、空间变换和路径规划；
- 不能只用游戏内通关证明学习；
- 必须加入从未出现过的地图和不同表达形式，单独测迁移；
- 如果未来宣称能促进数学或科学学习，需要另做外部测量，不能从空间关卡成绩直接推导。

## 学习机制

### 1. 引导式游戏，而非完全自由探索

引导式游戏强调：成人或系统有明确学习目标，孩子保留选择与主动权，同时在需要时获得提示、开放问题或示范。相关系统综述与元分析认为，引导式游戏在部分学习结果上优于自由游戏或直接教学，但不同研究对其定义和实施方式差异较大。[Skene et al., 2022](https://onlinelibrary.wiley.com/doi/10.1111/cdev.13730)、[Weisberg et al., 2016](https://www.psychologicalscience.org/journals/current-directions/0963721416645512/)

对应到产品：

- 系统给出清楚的问题，例如“让水流到两块农田”；
- 孩子自行选择部件、位置和尝试顺序；
- 提示从轻到重：指出现象、提醒约束、局部示范；
- 不直接替孩子完成，也不让孩子在没有边界的沙盒中迷失。

### 2. 有支架的探究循环

探究学习并不等于放任发现。Lazonder 和 Harmsen 对 72 项研究的元分析发现，指导对学习活动、任务成功和学习结果均有促进作用。[Lazonder & Harmsen, 2016](https://journals.sagepub.com/doi/abs/10.3102/0034654315627366)

每个任务采用固定的五步循环：

1. **观察**：水在哪里停住了，哪些地方发生了变化；
2. **预测**：运行前标出水可能经过的路径；
3. **搭建**：移动、旋转、组合有限的部件；
4. **实验**：启动水流，获得连续、可见的环境反馈；
5. **修正与表达**：根据结果调整，并用图示说明“为什么”。

其中“预测”不能省略。如果孩子只在运行后不断拖动，系统只能知道他最终成功，无法区分理解、记忆与碰巧试中。

### 3. 游戏规则与知识规则一致

数字游戏学习的元分析显示，游戏相对非游戏条件总体上可以改善学习结果，但效果取决于设计，并不是“加了游戏就有效”。Clark 等人的 K–16 元分析报告游戏与非游戏比较的平均效应量 g = 0.33，也发现强化设计后的游戏相对标准游戏有学习收益。[Clark et al., 2016](https://journals.sagepub.com/doi/10.3102/0034654315582065)

因此本产品不采用：

- 答完题才能获得水管；
- 正确后发星星、金币或抽卡；
- 用角色成长掩盖重复题库；
- 只统计正确率与在线时长。

水流方向、连接、坡度、容量和分支本身就是需要理解的规则。游戏奖励是岛屿真实恢复，而不是规则之外的一套经济系统。

### 4. 基于证据的隐性评估

Evidence-Centered Design（ECD）要求先说明“想对学习者作出什么判断”，再设计能诱发相关行为的任务，最后定义什么观察证据支持这个判断。ETS 关于游戏内嵌评估的研究将其用于形成性评估和学习支持。[Shute et al., 2008](https://www.ets.org/research/policy_research_reports/publications/report/2008/huwh.html)

产品必须依次设计：

- **能力模型**：具体训练什么；
- **证据模型**：什么行为可以支持或削弱判断；
- **任务模型**：什么任务会自然诱发这些行为；
- **反馈模型**：系统何时给什么程度的支架。

不能先做关卡，再从日志里挑几个好看的指标包装成能力报告。

## 首版能力模型

| 能力主张 | 可观察证据 | 反证或不确定信号 |
|---|---|---|
| C1：理解部件之间的空间关系 | 放置前能判断相邻、方向、连接口与障碍 | 大量无目的拖动，反复忽略明显障碍 |
| C2：能进行二维旋转与组合 | 在放置前选择正确朝向，逐步减少无效旋转 | 只能靠逐个角度试遍 |
| C3：能规划由起点到目标的路径 | 运行前预测路径，能从目标反推关键节点 | 每一步只响应局部，不考虑后续路线 |
| C4：能理解简单系统因果 | 能预测堵塞、分流、容量变化对下游的影响 | 只记住固定地图答案，条件变化后失效 |
| C5：能根据证据修正方案 | 失败后修改与观察结果相关的部件 | 失败后随机清空或重复相同动作 |
| C6：能迁移策略 | 在未见地图或不同视图中使用同一原则 | 只会复现已玩关卡 |

“坚持尝试”只能作为行为描述，不能直接写成“孩子具有成长型思维”；“快速完成”也不能直接推断为理解。

## 为什么是水岛，不是另外三个主题

| 主题 | 学术与机制匹配 | 主要问题 | 结论 |
|---|---|---|---|
| 水岛修复 | 水流提供连续可见反馈；容易承载路径、旋转、坡度、分流和工程迭代 | 物理规则必须简化但不能制造明显误解 | 首选 |
| 机械工坊 | 齿轮、传送带和顺序因果适合工程思维 | 机械概念多，首版开发与美术复杂度高 | 第二世界 |
| 太空站拓荒 | 目标感和冒险感强，适合资源系统 | 容易让幻想设定盖过学习规则，也容易引入科学误解 | 品牌成熟后使用 |
| 生态花园 | 家长价值感强，适合生命科学 | 真实生态反馈时间长、因果多且难隔离，不利于即时实验 | 不做首个核心机制 |

水岛的关键优势是：孩子能在数秒内看到假设造成的后果，同时世界恢复又能支持数周的长期目标。

## MVP 世界与故事

### 孩子的身份

孩子不是来“上科学课”，而是成为一名 **修复师**。固定角色身份不要强调“你是不是天生的小科学家”，而强调可重复的行动：

- 看一看发生了什么；
- 猜一猜水会去哪；
- 动手搭一个方案；
- 运行并观察；
- 根据证据再改一次。

### 世界设定

一座岛的古老水脉停止工作。岛上的植物、居民和机械没有消失，只是处于等待恢复的状态。孩子每解决一个系统问题，世界就产生持续变化：

- 枯萎的梯田恢复；
- 水车开始转动；
- 新道路和居民故事出现；
- 湿地重新吸引动物；
- 工坊获得新的部件。

叙事只负责赋予目标意义，不能替代科学解释。

### 第一章：六个任务

| 任务 | 核心变量 | 学习行为 |
|---|---|---|
| 1. 找回第一滴水 | 连通与方向 | 识别起点、目标和连接口 |
| 2. 转弯的山路 | 部件旋转 | 心理旋转后再放置 |
| 3. 水为什么不往上走 | 高低与路径 | 预测简单坡度影响 |
| 4. 两块田都要喝水 | 分支与分配 | 比较不同分流方案 |
| 5. 水库装不下了 | 容量与顺序 | 理解局部变化对下游的影响 |
| 6. 陌生的北岛 | 新地图、同规则 | 验证策略迁移，不提供原布局提示 |

每个任务只新增一个变量。不能在同一关同时引入坡度、容量、阀门和计时，否则无法判断孩子究竟理解了什么。

## 家长报告应该怎样写

家长端不输出虚假的综合分数，也不把孩子和同龄人排名。只报告有证据的行为：

> 本周观察：在三次水路任务中，孩子开始在运行前检查连接方向；遇到分流失败后，第二次尝试修改了上游节点。  
> 尚未确认：在全新地图中是否仍能使用相同策略。  
> 家庭延伸：请用纸画两条从厨房到阳台的路线，让孩子比较哪条转弯更少。

报告分成：

- **观察到的行为**；
- **暂时不能推断的结论**；
- **一个现实世界迁移活动**。

## 学术验证路线

### 阶段 A：交互可用性

对象：10–15 名 6–8 岁儿童。  
目标：确认孩子理解操作与任务，不评价学习效果。

记录：

- 第一次理解任务所需时间；
- 成人帮助次数；
- 预测步骤是否被理解；
- 失败后是否根据反馈修正；
- 随机拖动与有计划操作的比例。

### 阶段 B：学习可行性

对象：至少 30–60 名儿童，最好有教育心理或科学教育研究者参与。  
设计：前测、干预、后测，并包含未训练的新地图任务；条件允许时设置主动控制组，而不是只比较“玩前和玩后”。

至少测量：

- 训练关卡表现；
- 未训练地图的近迁移；
- 不同表达形式的空间任务；
- 一周后的保持；
- 孩子主动回访和主观乐趣。

### 阶段 C：对外效果声明

在没有完成可靠对照研究前，只能说：

- “围绕空间关系与工程迭代设计”；
- “记录孩子在游戏中的策略变化”；
- “帮助孩子练习预测、搭建、观察和修正”。

不能说：

- “提升智商”；
- “全面提升科学素养”；
- “玩 X 天提高空间能力 Y%”；
- “根据游戏行为诊断儿童能力”。

## 与国内课程方向的关系

教育部对《义务教育科学课程标准（2022 年版）》的说明强调小学科学的探究实践和工程实践，提出覆盖观察、实验探究、测量、制作、模拟实验、读图识图和工程实践等活动，并按 1–2、3–4、5–6 年级分段进阶。[教育部：小学科学实验教学基本目录说明](https://hudong.moe.gov.cn/jyb_xwfb/moe_2082/2023/2023_zl24/202311/t20231123_1091840.html)

本产品可以与这一方向相容，但“课程方向一致”不等于“经过课程认证”。首版更适合定位为家庭中的非正式学习产品，而非校内课程替代品。

## 下一步决策

在继续画世界和 UI 之前，先产出一页 Learning Design Brief，只确定四件事：

1. 第一能力是否只做空间路径与旋转；
2. 水流规则保留哪些真实约束、简化哪些约束；
3. 六个任务分别需要诱发什么证据；
4. 用什么未训练任务测迁移。

这四项确认后，才进入主题视觉和原型设计。
