# 地铁打字流量与 AdSense 接入评估

核验日期：2026-10-28，Asia/Shanghai。网站：https://metro.forgepane.com/ 。本次只读查询生产数据与公开规则，未申请广告账号、改站、部署或发送授权邮件。

## 判断

可以准备 AdSense 小规模试验，但当前收益规模不足以支持投入较多开发成本。优先处理上游授权、明确流量峰值来源和复访，再做不打断游戏的广告位。普通内容广告与 H5 游戏内广告应分开评估。

## 主要发现

- 10 月 15、19、20、21、23 日合计 6,383 次 page_view，占 7,599 次的 84.0%。其余 25 天仅 1,216 次，平均 48.6 次/日。不能按峰值外推稳定收入。
- 288 个开局身份里，8 个在至少两个不同自然日开局，占 2.8%。这是窗口内跨日复玩比例，不是 D1/D7 留存；清除 cookie、共享设备、账号恢复与跨设备会影响结果。单人窗口内最多活跃 5 天。
- 近 7 个完整自然日有 99 个开局身份、968 张票据、469 次成绩提交。
- 产品事件中苏州占开始游戏的 65.1%（2,031/3,121），上海 394、北京 174。这里是游玩线路城市，不代表用户所在地。
- RUM 国家分组仅返回 CN；桌面页面浏览约 91.0%，移动约 7.1%，平板约 1.9%。小量境外访问可能未进入样本，不能断言完全没有境外用户。
- 730 次 visits 中，约 710 次来源为空，百度和 MSN 各约 10 次；同站 referrer 的 5,500 次页面浏览不能当作外部获客。来源为空可能是手输、收藏、聊天应用或 Referrer 被移除，不能确定是小红书或自然搜索。
- 1,441 次成绩提交平均游玩约 152 秒，总计约 61 小时。未提交、放弃与离开的游戏不在这一时长内，不能当全站平均停留时间。

## 收益敏感性分析

Google 的页面 RPM = 收益 / 页面浏览量 × 1,000。[官方定义](https://support.google.com/adsense/answer/112030?hl=en)

以下只用于判断数量级，假设每月 6,230 次 RUM 页面浏览均落到可投放页面，页面 RPM 分别假设为 1、3、5 美元，对应约 6.23、18.69、31.15 美元/月。这些 RPM 不是本网站实测或行业报价，不能据此预测收入。只在部分内容页展示时，可变现页面量会下降；中国大陆网络下的广告加载、填充、广告屏蔽和审核结果尚未实测。

以假设页面 RPM 2 美元为例，100 美元/月需要约 50,000 次可变现页面浏览。当前应把广告视为小额实验，优先验证流量是否持续。

## 接入条件与项目缺口

1. **账号与内容。** Google 当前资格页要求优质原创内容、政策合规、源码控制权与成年申请者，没有列出统一的最低 PV 数字；低流量不是自动通过或拒绝的依据。[资格要求](https://support.google.com/adsense/answer/9724?hl=zh-Hans)。中国在注册支持范围，简繁中文均为支持语言。[地区](https://support.google.com/adsense/answer/13402307?hl=zh-Hans)、[语言](https://support.google.com/adsense/answer/9727?hl=en-GB)。本次没有访问私人 AdSense 账号，已有账号和域名审批状态未知。
2. **上游授权。** 本地 README 第 177 行明确提醒确认原始代码授权。实时 GitHub API 返回上游 `license: null`，根目录无 LICENSE，license API 404。[上游仓库](https://github.com/ridemountainpig/tw-metro-typing)。这不能排除作者另行书面授权；现有证据未确认商用许可。建议先取得明确授权，或核对并替换仍依赖且无授权的上游实现。
3. **根域名。** 一般站点按 `forgepane.com` 加入 AdSense，`metro.forgepane.com` 不能当普通独立站点提交；根域属于 BeamJoin，后续申请和 ads.txt 需要协调该根站配置，广告脚本仍可只装在地铁站。[网站 URL 要求](https://support.google.com/adsense/answer/2784438?hl=en)、[站点管理](https://support.google.com/adsense/answer/12170421?hl=en)。不要为地铁广告顺带给 BeamJoin 工作台安装广告。
4. **ads.txt。** 实时 GET 根域 `/ads.txt` 返回 404；地铁子域 `/ads.txt` 返回 200 HTML SPA 外壳，不能当有效 ads.txt。拿到真实 publisher ID 后再配置正确文本记录。只有子域 seller/publisher ID 不同时才需按官方规则处理子域转介。[ads.txt 规则](https://support.google.com/adsense/answer/9785052?hl=en)
5. **隐私。** 本地代码检索未确认独立隐私页面；线上 bundle 存在“隐私”字样，不能据此确认已经覆盖广告 cookies 与第三方处理。后续必须检查完整页面与可达入口，补充准确披露。[官方隐私内容要求](https://support.google.com/adsense/answer/1348695?hl=en-GB)。向 EEA、英国、瑞士用户提供个性化广告时需满足 Google 认证 CMP 等要求。[CMP](https://support.google.com/adsense/answer/13554116?hl=en-GB)

## 推荐实施顺序

先确认授权和 AdSense/根域审批状态，再完善实际存在的游戏玩法介绍、作者/联系入口、数据来源及隐私说明。内容应帮助玩家，不为凑审核页数批量生成文章。

第一轮仅考虑城市/线路介绍等有充分内容的非游戏操作区域放一个手动广告位，不先启用全站自动广告。普通 AdSense 内容广告应远离游戏控件；Google 强烈建议距离游戏至少 150px，或从游戏操作页移除。[游戏页面广告布局](https://support.google.com/adsense/answer/2768340?hl=en)

游戏内插屏和激励广告使用 H5 Games Ads，它需要已批准的 AdSense 账号并另行申请，批准没有保证。[申请规则](https://support.google.com/adsense/answer/1705831?hl=en)、[产品说明](https://support.google.com/adsense/answer/9959170?hl=en)。现阶段不为广告改变计时、成绩公平性或打字节奏。

获批后再做 2–4 周受控实验，比较广告加载成功率、实际覆盖率、页面 RPM、开始游戏比例、完成情况与跨日复玩，同时记录峰值活动来源。当前数据主要缺口是可归因来源与去重留存，而不是缺少更多页面点击统计。
