# NEX 含义核验

核验日期：2026-09-09。通过 Hi CLI 搜索 REDoc 并读取正文。

NEX 的官方写法为 Native Engine for Agent SandboX，取 Native 的 N、Engine 的 E、Sandbox 的 X。平台概念文档将其定义为面向 Agent 开发和运行的云原生平台，提供 Agent 应用从定义到运行的全生命周期管理。Sandbox 为 Agent 提供隔离执行环境；AgentApp 是可部署、可调度的 Agent 应用实体。

用户引用的工作项包含“澄清隔离、协议统一、NEX 运行守护、增强数据泄漏检查、镜像预热、完善基础镜像&业务镜像的标准化制作流程”。本次未定位到该句原始文档，不能确认“澄清隔离”的含义，也不能据此认定这些工作已完成。
