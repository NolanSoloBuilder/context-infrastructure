## 一、概述

MindSpace 移动端提供了多种用户认证方式：

- 邮箱验证码注册 - 无密码快速注册
- 邮箱密码登录 - 传统账号密码登录
- Google 第三方登录 - OAuth2.0 快速登录
- 第三方应用授权 - Twitter、Gmail、Notion 等应用集成

Base URL: https://mindspace.click/api/v1

## 四、邮箱验证码注册

```Plain Text
1. 验证邮箱是否已注册
   ↓
2. 发送验证码到邮箱
   ↓
3. 提交验证码完成注册
```

### Step 1: 验证邮箱

Endpoint: POST /m/user/email/validate

请求：

```Plain Text
{
  "email": "user@example.com"
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Email available",
  "data": {
    "emailExists": false
  }
}
```

前端逻辑:

- 如果 emailExists = true，提示用户邮箱已注册，引导去登录
- 如果 emailExists = false，继续注册流程

### Step 2: 发送验证码

Endpoint: POST /m/user/email/verification

请求：

```Plain Text
{
  "email": "user@example.com",
  "password": "YourPassword123!"
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Email verification code sent",
  "data": {
    "verification_event_id": "67891d4a962b2171f53edb3f2"
  }
}
```

重要:

- verification_event_id 需要保存，用于下一步验证
- 验证码有效期：10 分钟
- 冷却时间：60 秒（防止频繁发送）

### Step 3: 提交验证码注册

Endpoint: POST /m/user/register

请求：

```JSON
{
  "email": "user@example.com",
  "password": "YourPassword123!",
  "verification_event_id": "67891d4a962b2171f53edb3f2",
  "verification_code": "123456"
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Registration successful",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
}
```

客户端处理:

1. 保存 token 和 refresh_token 到本地存储
2. 设置 HTTP 请求头：Authorization: Bearer {token}
3. 跳转到主页

## 七、密码重置

### 场景一：已登录用户修改密码

Endpoint: POST /m/user/password/reset

请求头：

```Plain Text
Authorization: Bearer {access_token}
```

请求：

```Plain Text
{
  "old_password": "OldPassword123!",
  "new_password": "NewPassword456!"
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Reset password success",
  "data": null
}
```

### 场景二：忘记密码（未登录）

#### Step 1: 发送密码重置验证码

Endpoint: POST /user/password/reset/code

请求：

```Plain Text
{
  "email": "user@example.com"
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Password reset code sent",
  "data": {
    "verification_event_id": "67891d4a962b2171f53edb3f2"
  }
}
```

#### Step 2: 验证验证码并重置密码

Endpoint: POST /user/password/reset/verify

请求：

```JSON
{
  "email": "user@example.com",
  "verification_event_id": "67891d4a962b2171f53edb3f2",
  "verification_code": "123456",
  "new_password": "NewPassword456!",
  "confirm_password": "NewPassword456!"
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Reset password success",
  "data": null
}
```

## 八、第三方应用授权

MindSpace 支持用户授权连接第三方应用，用于数据同步和内容导入。

### 支持的平台

- Twitter - 导入推文和关注
- Gmail - 邮件整理和智能分类
- Notion - 笔记同步

```Plain Text
1. 获取授权 URL
   ↓
2. 打开浏览器进行授权
   ↓
3. 回调后台完成绑定
```

### Twitter 授权

Endpoint: GET /integration/twitter/v1/auth/login

请求头:

```Plain Text
Authorization: Bearer {access_token}
```

查询参数:

- state (optional): 自定义状态参数
- scope (optional): 授权范围

返回：

```JSON
{
  "success": true,
  "msg": "Authorization URL generated",
  "data": {
    "authorization_url": "https://twitter.com/i/oauth2/authorize?..."
  }
}
```

### Gmail 授权

Endpoint: GET /integration/gmail/v1/auth/login

请求头:

```Plain Text
Authorization: Bearer {access_token}
```

查询参数:

- state (optional): 自定义状态参数
- scope (optional): 授权范围（默认: https://www.googleapis.com/auth/gmail.readonly）
- prompt (optional): consent / select_account
- access_type (optional): offline 用于获取 refresh token

返回：

```JSON
{
  "success": true,
  "msg": "Authorization URL generated",
  "data": {
    "authorization_url": "https://accounts.google.com/o/oauth2/v2/auth?..."
  }
}
```

### Notion 授权

Endpoint: GET /integration/notion/v1/auth/login

请求头:

```Plain Text
Authorization: Bearer {access_token}
```

查询参数:

- state (optional): 自定义状态参数
- owner (optional): workspace owner

返回：

```JSON
{
  "success": true,
  "msg": "Authorization URL generated",
  "data": {
    "authorization_url": "https://api.notion.com/v1/oauth/authorize?..."
  }
}
```

## 九、Token 管理

### 在请求中使用 Token

所有需要认证的 API 都需要在请求头中携带 Access Token：

```Plain Text
GET /m/user/profile HTTP/1.1
Host: api.mindspace.com
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

## 十、Token刷新

### Token 刷新

当 Access Token 过期（120分钟后），使用 Refresh Token 获取新的 Access Token。

Endpoint: POST /token/refresh（需要实现）

请求体:

```Plain Text
{
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

返回：

```JSON
{
  "success": true,
  "msg": "Token refreshed",
  "data": {
    "token": "new_access_token...",
    "refresh_token": "new_refresh_token..."
  }
}
```
