# MVP产品需求文档：智能信息助手

## 1. 文档概述

- **产品名称**： 智能信息助手（MVP）
- **文档版本**： 1.0
- **MVP目标**： 验证用户是否接受并依赖“AI解读”作为其消费订阅内容的核心方式，并认为其比传统RSS阅读器提供更高价值。
- **核心假设**： 用户不愿意再逐篇阅读原始文章，而是希望由一个AI助手为其总结、整合并主动发现信息。
- **目标用户**： 信息重度依赖者、专业人士、知识工作者。
- **成功指标**：（待定）

  1. **用户留存率**： 周活跃用户次周留存率 > 40%。
  2. **核心功能使用率**： > 60%的活跃用户每周至少点击阅读一个“合辑卡片”。
  3. **价值认可度**： 在初期用户调研中，>70%的用户认为“AI解读”使其信息获取效率“显著提升”。

## 2. 核心流程

- **启动与引导**

  - 用户登录 -> 第三方数据授权 ->  填写问卷-> 进入智能信息流首页。
- **内容消费**

  - 合辑阅读（核心）
  
    - 用户在首页浏览A板块（每日订阅更新简报）或B板块（为我发现）的合辑卡片 -> 点击感兴趣的卡片 -> 进入合辑阅读器（AI解读对话界面）进行深度阅读与对话。
  - 单篇阅读（次级）
  
    - 用户在合辑阅读器中浏览AI生成内容 -> 点击信息源-> 进入单篇阅读器（AI总结 / 原文）进行深度阅读与对话。
    - 用户浏览订阅管理页-> 点击感兴趣的订阅源-> 进入订阅源发布主页 -> 点击单篇-> 进入单篇阅读器（AI总结 / 原文）进行深度阅读与对话。
- **订阅管理**

  - 用户通过首页的“+”号添加初始订阅源  （核心）
  - 用户点击感兴趣的订阅源（未订阅）-> 进入订阅源发布主页 -> 订阅信息源（次级）
  - 用户通过信息流推送添加订阅源； （排期优先级低）
  - 用户在合辑中接受主动订阅源推荐并添加订阅源（排期优先级低）
- **意图反馈循环**

  1. 用户在合辑阅读器中为内容点赞/点踩，系统据此优化后续推荐。（基础，优先开发）
  2. 用户在合辑阅读器中对话，识别新的意图/ 深化意图理解；（核心）
  3. 用户在智能流中，与主动意图反馈器交互（点击卡片），完成意图输入；（排期优先级低）

## 3. 功能模块与优先级

优先级说明：

- M级：must have：MVP必要核心功能，最优先完成。
- S级：Should have：重要但非关键的功能，可以暂时没有，但缺失会影响用户体验或效率。
- C级：Could have：附加的、次要的功能，增加用户便利或吸引力，但不会影响核心业务，可以放在后续迭代中实现。

### 模块一：信息流智能合辑 (P0)

- **M1.1 智能信息流首页 （日更）**功能说明：首页内容为每日生成，固定更新。系统每天基于用户订阅源的最新内容和用户画像，自动生成全新的统领性导语与合辑卡片。

  - **每日简报导语**
  
    - 功能描述：将用户已订阅的源的最新内容进行聚合，生成一个统一的“每日认知焦点导语”，并据此呈现不超过3条的“每日合辑卡片”。
    - 核心价值：通过一个统领性的AI导语，为用户设定当日信息消费的认知基调和优先级，实现从“信息列表”到“认知焦点”的转变。
    - 呈现形式：
    
      1. 【统领性导语】：位于板块顶部，以加粗或特殊样式显示。它基于当日所有订阅内容，提炼出核心脉络，为用户提供一个高层次的“今日信息解读”。
      2. 合辑卡片：导语下方陈列具体卡片，每张卡片都是对导语中某一核心脉络的展开，包含AI生成的标题与1-2句具体解读。
  - **合辑卡片A类：订阅更新**
  
    - 功能： 将用户已订阅的源的最新内容，按照订阅源分组（社交媒体/视频/播客/文章）进行聚合，生成不超过2-4条的“每日合辑卡片“。
    - 呈现： 卡片显示AI生成的标题与1-2句导语。
    - **限制(MVP)**： 仅支持按照订阅源分组聚合，合辑生成规则固定（如按时间+模型总结）。
    - 11.4 讨论：总体期待：卡片应该是「**信息密度高的当日总结**」**关键词：**待讨论：
    
      > 「上来就是一篇很有信息量的总结，对我来说是‘今天发生了什么 + 有什么洞察’。」
    
      - 信息密度高，不要空洞摘要；
      - 第一屏就能「获取认知」而不是「提示内容」；
      - 读完这一张卡片，就能了解当天重点讨论的主题与行业新趋势。
    
      1. 按照讨论的内容来聚合还是按照账号来聚合？
      2. 呈现：除了呈现总结，信息源外显到什么程度？（只展示值得深入阅读的？）
    - **合辑卡片B类：意图卡片**
    
      - 功能： 系统从预设的、有限的优质公开源中，基于简单规则（用户画像-意图分类-Prompt）生成4-5张“个性意图卡片”。
      - 呈现： 卡片显示AI生成的标题与导语。
      - **数据规则**： 推荐源列表由手动维护，基于模型推理的用户订阅源意图召回；
- **M1.2 合辑阅读器（AI解读对话界面）**

  - 功能： 点击卡片后进入一个以AI助手对话为核心的界面。
  
    - **初始内容**： 首先完整展示生成该合辑的AI总结（即卡片的扩展版）。
    - **持续对话**： 用户可基于此合辑内容与AI进行多轮对话（追问、总结等），用户输入将用于画像和意图的持续更新。
    - **内容溯源**： 必须提供一个“信息源”按钮，点击后可查看生成此合辑所引用的所有原始文章链接（可跳转）。
  - **限制(MVP)**： 无快捷Prompt，无收藏/分享整个线程。
- **S1.1:  合辑反馈机制 (赞/踩)**

  - 功能描述：在每个合辑卡片和合辑阅读器内，提供“点赞”/“点踩”按钮。
  - 用户价值：轻点赞同或反对，让信息助手更快学习内容偏好。
  - 呈现形式：
  
    - 在合辑卡片的右下角，以及合辑阅读器的右下角，固定显示“赞”和“踩”图标。点击后即有视觉反馈但不中断当前浏览。
- **C1.1：合辑阅读器（收藏与分享整个对话线程）**
- **C1.2：合辑阅读器 （用户自定义快捷Prompt）**
- **C1.3：合辑阅读器（ 智能订阅源推荐）**

### 模块二：内容阅读与订阅源探索 （P1）

- **M2.1 单篇文章阅读器**

  - 功能描述：
  
    - 从“内容溯源”列表点击原文链接后，在应用内打开一个单篇文章阅读器。
    - 提供“AI解读模式”tab，点击后可在侧边栏或新页面获得对该文章的AI总结。
  - 用户价值：一键切换AI总结与原文，兼顾阅读效率与深度求证。
  - **MVP（限制）：**不做播客、视频内容的视频/音频播放（MVP聚焦文本）
- **S2.1 RSS订阅源专栏页**

  - 功能描述：
  
    - 为每一个订阅源提供一个独立的专栏页面。此页面按时间倒序清晰陈列该源所有的历史更新。
    - 页面头部提供明确的“订阅”与“取消订阅”按钮。
    - 点击文章跳转至 S1 单篇文章阅读器。
  - 用户价值：直达信息源头，浏览源站全部内容，订阅前先验质量。
  - 呈现形式：
  
    - 顶部为信息源头像、名称和简介，以及一个显眼的“订阅/取消订阅”按钮。
    - 下方为纯净的文章列表，每行包含文章标题、发布日期和预估阅读时长。

### 模块三：动态订阅管理 （P0）

- **M3.1 订阅源的增改查**

  - 添加功能： 通过首页的“+”号，支持手动输入URL的方式添加订阅源。
  - **订阅源管理侧边栏**（删**/** 改/查功能） 在全局侧边栏中，自动化订阅源分组，-以列表形式展示所有已订阅源，支持取消订阅。
- **C3.1: 添加订阅源：OPML导入**
- **C3.2: 添加订阅源：自然语言订阅**
- **C3.3: 订阅源主动推荐 （智能信息流 ）**

  - 功能描述：在首页信息流中，插入推荐订阅源卡片，支持一键订阅。
  - 用户价值：无需费力搜寻，在浏览中发现并一键订阅优质信息源。
  - 呈现形式：
  
    - 2-3张订阅源卡片 横排，但带有“推荐订阅”标签。卡片内包含源名称、头像、一句推荐语（如：“科技领域热门源”）和一个显眼的“+”号订阅按钮。点击“+”后，按钮变为“已订阅”状态。

### 模块四：智能意图收集 （P1）

- **S3.1: 信息流意图收集器**（Chatbox）

  - 功能描述：
  
    - 在智能信息流首页的底部，固定一个对话框，允许用户用自然语言主动输入兴趣点。
  - 用户价值：随时告诉AI你还想了解什么，让明日简报更懂你。
  - 呈现形式：
  
    - 一个始终固定在信息流底部的卡片，上面有输入框和提示文字“您想深入了解今天的哪个话题？”。用户输入并回车后，卡片显示“已收到您的兴趣，将在明天的更新中为您呈现”。
- **C3.1：信息流意图收集器**（系统主动）

  - **AI主动甄别用户意图，以组建形式主动询问并收集反馈。无缝衔接进信息流中。**
