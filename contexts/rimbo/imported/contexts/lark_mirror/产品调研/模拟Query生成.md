# 模拟Query生成



Prompt

为每一种职业画像（或画像组合）设计一套“信息卡片”模板。共有5种信息类型： 

**领域态势        Domain-Radar        持续追踪自己关心领域的最新趋势与事件变化。** 

**实体追随        Entity-Follow        跟进特定人物/公司或产品的进展与关键动态与评论。** 

**深度洞察        Deep-Synthesis        从跨来源的分析中提炼趋势与机会洞察。** 

**内部案例 / 经验分享        internal_case        团队或个人的复盘与实践经验。** 

**工具技能提升        Tool-Skills-Uplift        在购买 / 启用新工具后快速上手并提高使用效率。** 

**内容角度/模拟Query： 基于该角色的工作职责和关注点，预设一系列检索Query。**



Task

请以【Product Management】【AI / ML】【Social / Media Platforms】作为用户的职业画像，为每个信息类型预生成一系列的模拟Query。





##  用户画像

**Product Manager · AI/ML · Social / Media Platforms**  
 目标：

> 管理基于 AI 推荐、生成式创作或社交互动算法的产品；  
>  关注内容生态、算法机制、用户增长与创作工具的结合。
