## **6.1 时间衰减的适用范围**

时间衰减作用于**内容层**，不直接作用于信源的 L1_score。

L1_score 的变化由4.7节的动态更新规则控制。

时间衰减解决的问题是：同一条内容，发布时间越久，对用户当前决策的参考价值越低。

衰减公式：

```Plain Text
Score(t) = Score₀ × e^(−λt)
t = 内容发布至今的小时数
λ = 按内容类型分别设定
```

## **6.3 衰减特别规则**

**刷新机制：** 新的独立来源出现 → 自动刷新内容寿命，重置衰减起点（t 归零）

**窗口关闭信号：** 内容已被多家主流媒体广泛报道 → 决策窗口标注为「已关闭」，内容评分中的决策时间窗口维度降至 0.20，不再因新来源刷新

**Event-driven 型信源：** 监管披露、法律文件等 Event-driven 型内容，衰减起点从文件生效日期计算，而非抓取时间

# L2 — 证据出处（Claim Provenance）

这是本评分体系最重要的层级。同一信源的同一篇文章，可能基于监管文件，也可能基于匿名消息源——这两种情况不应该得到相同的分数。L2 评估的是这条具体内容的证据来自哪里。

**证据类型与评分**

| **证据类型** | **L2** | **一级市场意义与判断要点** |
|-|-|-|
| **法律/监管原始文件** | 1.00 | 中基协备案（反映融资实际完成）、SEC Form D、工商股权变更。公司无法造假，是最强确认信号。 |
| **公共替代数据** | 0.90 | 招聘岗位变化、专利申请、供应链采购。非内部消息，是公开可观察的运营痕迹，往往领先公开声明 3-6 个月。独立性极高。 |
| **创始人/高管署名表态** | 0.75 | 对自身公司事实有权威性，但对行业判断不自动更权威。必须标注利益相关。 |
| **多独立命名来源** | 0.70 | 多个相互独立的知情人交叉确认。注意：一级市场的「多源确认」有时意味着信息已扩散，决策窗口可能收窄。 |
| **匿名消息源** | 0.40 | 在一级市场往往来自员工或竞争对手，动机复杂。必须在 Brief 中标注，并等待运营痕迹数据交叉验证后再行动。 |
| **二手转载** | 0.25 | 转载他人报道，未做独立核实。系统优先追溯原始来源，以原始来源的 L2 为准。 |

| **独立性判断关键规则** |
|-|
| • 三家媒体都转引同一份融资公告 = 只算一次确认，不算三次独立确认 |
| • 招聘数据 + 专利申请 + 供应链信号同时出现 = 三个独立证据族，可以叠加事件置信度 |
| • 「多源确认」是风险信号：信息被广泛报道往往意味着竞争加剧、估值抬高，决策窗口可能已经关闭 |
| • 平台纠错层（如 X Community Notes）与原帖分开建模，不自动提升原帖的 L2 分数 |

 **多源聚合公式（独立性感知）**

在事件层合并多条内容时，使用以下公式确保只有真正独立的来源才能提升事件置信度：

| **单条内容置信度   = L1 × L2 × L3**  <br/>**事件置信度 =   1 − ∏(1 − independence_i × 单条置信度_i)**  <br/>**independence_i   示例：**  <br/>  **同一消息的多次转载：independence ≈ 0.1**  <br/>  **不同记者采访不同知情人：independence ≈ 0.9**  <br/>  **完全独立的原始文件（招聘数据 + 专利 + 法律文件）：independence   = 1.0** |
|-|

# L3 — 内容质量

对单条内容本身价值的评估，独立于信源和证据来源。这一层直接对应用户「这条值不值得看」的判断。

**一票否决（先于评分执行）**

| **否决条件** | **处理方式** | **说明** |
|-|-|-|
| 纯技术底层，无商业应用 | L3 强制 < 0.2 | 只讲模型架构或代码，无产品落地/增长/变现内容 |
| PR 稿/融资通稿（无实质增量） | L3 强制 < 0.2 | 只有金额无投资人结构/用途细节的融资公告 |
| 老生常谈（无信息增量） | L3 强制 < 0.3 | 信息不对称度 < 0.2 且   Cognitive Jump < 0.2 |
| 卖货/水军/公关稿 | L1 Independence → 0；过滤 | 明显服务于推广或带节奏 |
| MNPI 风险内容 | 进入 Legal Gate，暂停推送 | 疑似包含未公开重大信息，人工审核 |

**评分维度**

| **维度** | **权重** | **一级市场定义** | **高分条件** |
|-|-|-|-|
| Information Asymmetry（信息不对称度） | 30% | 这条信息是市场上少数人知道的，还是已经广泛传播？ | 内幕机制、非公开逻辑、运营痕迹深度解读；大众媒体广泛报道 = 低分（可能已错过窗口） |
| Decision Window（决策时间窗口） | 25% | 这条信息的投资决策窗口还开着吗？不只是「新不新」，而是「能不能行动」 | 信息刚出现且赛道未拥挤 = 高分；信息已广泛传播或赛道已有头部定局 = 低分 |
| Structural Signal（结构性信号） | 20% | 是否揭示了某个行业/公司的底层逻辑变化，而非表面事件 | 融资节奏异常、关键人才密集流入、客户结构突变、技术路线切换 = 高分；单次融资公告无细节 = 低分 |
| Cognitive Jump（认知跳跃度） | 15% | 与该公司/赛道上一次公开信号相比，这条信息揭示了多大的认知跳跃 | 估值倍数跳变、投资人名单出现意外背书、融资用途与历史战略不符 = 高分；符合既有叙事 = 中分 |
| Scene Support（场景支撑） | 10% | 是否有具体数据/案例支撑，而非泛泛而谈 | 有具体数字、时间、主体、事件链条 = 高分；「据悉将会」类无支撑 = 低分 |

**Cognitive Jump 详细判断标准**

| **场景** | **得分** | **说明** |
|-|-|-|
| 估值相对上轮跳变 > 3x | 0.95 | 市场对这个赛道重新定价，背后可能有新叙事或非公开信息支撑 |
| 投资人名单出现意外背书（跨界/罕见） | 0.90 | 某个不常见机构进场，往往意味着有非公开信息支撑其判断 |
| 融资规模/节奏与历史相比异常 | 0.85 | 比上轮快 50% 以上或规模远超行业均值，暗示竞争窗口收窄 |
| 创始团队背景与赛道明显不符 | 0.80 | 这种不匹配本身是信号，往往说明创始人掌握了某种非公开信息或资源 |
| 关键人才密集流入（30天内3人以上） | 0.75 | 反映内部信心或战略转向，比公开声明更可信 |
| 融资用途与历史战略明显不符 | 0.70 | 一直做 B2B 的公司突然扩张消费端，暗示重大战略调整 |
| 符合既有叙事，信息量有限 | 0.30 | 确认但不增加认知，不改变投资判断 |

# L4 — 个性化匹配

一级市场投资人的个性化需求高度集中：不只关心已投项目，更关心竞品动态、同赛道标的和潜在投资标的。

| **维度** | **权重** | **定义** | **计算方式** | **冷启动默认** |
|-|-|-|-|-|
| Portfolio Match（投资组合匹配） | 35% | 涉及已投项目、竞品或同赛道竞争对手 | 已投直接相关=1.0；同赛道竞品=0.8；相关赛道=0.5；无关=0.1 | 0.3 |
| Thesis Match（投资逻辑匹配） | 30% | 是否与用户当前主要投资逻辑/关注赛道重合 | 完全匹配核心 thesis=1.0；相关 thesis=0.6；无关=0.1 | 0.5 |
| Stage Match（阶段匹配） | 20% | 涉及的轮次是否在用户关注的投资阶段内 | 完全匹配（如只投A轮）=1.0；相邻阶段=0.5；跨阶段=0.2 | 0.5 |
| Behavior Match（行为匹配） | 15% | 用户历史上对同类信号的互动频率 | 基于点击/标注/停留时长计算 | 0.5 |

| **L4 = 0.35   × Portfolio Match + 0.30 × Thesis Match**  <br/>   **+ 0.20 × Stage Match + 0.15 × Behavior   Match** |

# 7. 时间衰减

一级市场的时间衰减远慢于二级市场：融资信号的决策窗口是周级而非小时级，运营痕迹信号的价值可持续数月。

| **Score(t) =   Score₀ × e^(-λt)   其中 t = 发布至今的小时数**  <br/>   <br/>**融资/估值/并购类         λ = 0.005   半衰期 ≈ 6 天**  <br/>**人事变动/高管加入类       λ = 0.003   半衰期 ≈ 10 天**  <br/>**招聘/专利/运营痕迹类       λ = 0.001   半衰期 ≈ 1 个月**  <br/>**行业趋势/监管/赛道结构类 λ = 0.0005  半衰期 ≈ 2 个月**  <br/>   <br/>**特别规则：**  <br/>  **新的独立来源出现 → 自动刷新事件寿命（重置衰减起点）**  <br/>  **信息已被多家主流媒体广泛报道 → Decision Window 降至 0.2（窗口关闭信号）** |
|-|





Perspectives 模块（YES/NO 评分规则）

一级市场的 Perspectives 核心是：对同一个标的/赛道，展示不同投资判断——看多（Long）和看空（Short/Pass）以及背后的逻辑差异。

| **Step 1：每条 Opinion/Analysis 内容独立跑 L1×L2×L3×L4 完整评分**  <br/>**Step 2：按 stance 标签分组**  <br/>         **YES/Long 池：看多该标的/赛道**  <br/>         **NO/Short 池：看空、Pass 或质疑**  <br/>**Step 3：每组按 Final Score 排序，取 Top N**  <br/>**Step 4：NO 池设下限——至少保留 1 条**  <br/>         **若 NO 池最高分 < 0.4，加标注：**  <br/>         **「市场看空声音较少，以下为现有最高质量的反向声音」**  <br/>**Step 5：YES/NO 百分比用 L3 分加权计算**  <br/>         **YES% = Σ(YES内容 L3分)   / Σ(所有进入Brief内容 L3分)**  <br/>         **NO%    = Σ(NO内容 L3分)  / Σ(所有进入Brief内容 L3分)** |
|-|

| **一级市场 Perspectives 特别说明** |
|-|
| • 高度看多一致性本身是风险信号：几乎全是看多声音，可能意味着估值已经透支 |
| • 看空观点的来源极重要：有过同赛道失败经历的投资人的 Pass 理由，比普通媒体评论价值高得多 |
| • 利益冲突标注在这里尤其关键：已投该赛道的机构合伙人的看多观点，必须标注 ⚠️ 利益相关 |

# Brief 展示规范与示例

评分结果在 Brief 中必须可分解展示。一级市场投资人需要看到的不只是「这条信号重要」，而是「为什么重要、窗口还有多久、来源是否可信、有没有利益冲突」。



**9.1 每条内容的展示标签**

| **标签** | **展示位置** | **内容** |
|-|-|-|
| 信源类型徽标 | 信号标题旁 | 法律文件 / 公共替代数据 / 行业媒体 / 创始人表态 / 匿名消息源 |
| 证据出处标注 | 信源名称旁 | 原始文件 / 运营痕迹 / 署名采访 / 匿名消息源 |
| 利益相关标记 | 信源名称旁 | ⚠️ 利益相关（创始人/已投机构表态时自动显示） |
| 决策窗口状态 | 信号卡片顶部 | 窗口开启 / 窗口收窄（已多家报道）/ 窗口关闭 |
| 分数明细 | 展开详情 | L1 / L2 / L3 分别显示，不只显示黑盒 Final   Score |
| 归因链 | 「查看原文」展开 | 信源 → 证据类型 → 原始段落，完整可追溯 |
