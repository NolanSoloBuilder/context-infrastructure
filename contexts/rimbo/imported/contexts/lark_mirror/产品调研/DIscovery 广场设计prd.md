# 一、监测类（Monitoring Skills）— 最容易起量



## AI 热点自动追踪

**用途**

-  想快速知道 AI 圈今天发生了什么（替代刷 X） 

**输入**

-  X / Google / YouTube / Tech Blog 

**输出**

-  Top 5 热点 + 去重 + 结构化摘要 
-  🔺 热度变化（+趋势） 

**UI**

-  Run now / 每日 9:00 推送 
-  输出卡片（类似你那张图） 

---

## 融资 / 并购信号监测

**用途**

-  投资人/从业者关注钱流向哪里 

**输入**

-  新闻 / PR / 数据库（Crunchbase 类） 

**输出**

-  新融资事件 + 轮次 + 赛道聚类 
-  📊 “本周资本流向变化” 

**UI**

-  Filter：AI / Bio / Web3 
-  输出 timeline + summary 

---

## IR / 财报变动追踪（高价值）

**用途**

-  跟踪公司基本面变化 

**输入**

-  IR 官网 / Earnings Call / SEC 

**输出**

-  🧠 “关键指标变化” 
-  🧠 “管理层表述变化” 

（例如针对 NVIDIA）

**UI**

-  对比视图（本次 vs 上次） 

---

# 🧩 二、分析类（Synthesis Skills）— 拉开差距

## AI 行业趋势自动分析

**用途**

-  不想自己总结趋势 

**输入**

-  播客 + 新闻 + 技术文章 

**输出**

-  🧩 3 条主要趋势 
-  🧩 每条趋势的证据链 

**UI**

-  “本周趋势报告”（一屏） 

---

## 技术热点 → 商业化路径分析

**用途**

-  判断“这个技术能不能赚钱” 

**输入**

-  Paper + 产品发布 + VC 观点 

**输出**

-  🧠 技术成熟度 
-  💰 商业化路径 
-  ⏱ timing 判断 

---

## 产业链 & 利润池分析

**用途**

-  投资人核心能力 

**输入**

-  财报 / 行业报告 / 新闻 

**输出**

-  🧩 产业链图 
-  💰 利润分布变化
