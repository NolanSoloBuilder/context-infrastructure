**News 增量筛选**

原来的 News 要求信息与「用户关注的实体或主题相关」，这个 task 在此基础上加了：

- 必须包含**能力边界描述**，不接受空壳发布新闻
- 必须是**已上线产品**，排除预告和路线图
- 优先收录有**横向对比锚点**的新闻（基准分数、价格对比）

**Signal 增量筛选**

原来的 Signal 要求识别「结构变化」，这个 task 在此基础上加了：

- Signal 的结构变化必须指向**技术方向**，不是公司相对位置
- 必须有**技术路线归属判断**（通用 LLM / 多模态 / 具身 / 空间智能 / Agent）
- 必须由**至少 2 条 Facts 形成 Pattern**，单次发布不构成 Signal

**Perspective 增量筛选**

原来的 Perspective 只要求观点能归入 Yes/No，这个 task 在此基础上加了：

- Yes/No 的问题必须围绕**技术方向是否成立**，不是围绕竞争格局
- No 侧必须有**开发者社区或实际使用数据**作为佐证，防止变成纯机构观点
