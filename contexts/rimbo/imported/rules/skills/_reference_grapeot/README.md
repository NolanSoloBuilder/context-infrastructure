# Reference: grapeot 个人 skills

这里收录的是上游仓库里偏 grapeot 个人创作者向的 skills——Twitter（Typefully）、newsletter（Kit）、博客流量（GA4）、个人通知邮件、个人发布、博客切片、视频转录、Slide 风格化、个人化方法论等。

## AI 加载策略

**默认不加载这部分**。和 rimbo 团队工作没有直接关系，调用任何 typefully/kit/ga4/send_email 这些工具都需要 grapeot 自己的密钥和配置，团队成员既没有也用不上。

只在两种情形查阅：

1. 用户明确说"参考鸭哥之前怎么做的"
2. 团队想新做一个类似的能力（例如要做团队 newsletter 发布），把 reference 当作起点

## 与团队 skills 的关系
