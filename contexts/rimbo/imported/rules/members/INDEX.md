## 角色约定

为了 AI 在加载 profile 时知道当前对话者的视角偏好，约定几类常见角色（不是组织职级，是工作视角）：

- `engineer`：以代码 / 系统 / 工具为主要产物
- `pm`：以产品规划 / 决策 / 协调为主要产物
- `designer`：以交互 / 视觉 / 用户体验为主要产物
- `researcher`：以调研 / 分析 / 实验为主要产物
- `gtm`：以社媒 / 内容 / 增长 / 海外市场为主要产物
- `lead`：兼具技术决策与协调，跨多类产物

一人可以多个角色（用 `+` 连接），AI 会根据当前对话内容自动取其中相关的视角。
