# 铝型材 DIY｜学习计划

更新：2026-09-23

## 学习目标与起点

目标：先理解铝型材的材料、截面和框架受力，再能独立画出桌、架、柜类方案；对指定载荷下的梁挠度、主要风险和物料成本做有边界的估算，最终整理可向供应商询价的图纸、切割清单与 BOM。具体作品等完成基础学习后再选。

已确认基础：做过简单 DIY，有基础工具。机械设计、CAD、材料力学及型材连接件知识尚未确认。

学习模式：结合[AI 铝型材创意平台调研](../../survey_sessions/aluminum_creative_platform_survey_20260923.md)，重点沿“需求 → 设计 → 校核 → 加工 → 采购 → 装配”学习。该调研是场景材料，不代表已经掌握其中的工程知识。知识基础由用户于 2026-09-23 确认。

## 完成标准

1. 能从外形尺寸、净空、载荷、使用环境写出设计约束，并画出尺寸图与受力路径。
2. 能按供应商的具体 SKU 核对截面惯性矩、槽口、连接件、端部加工和表面处理，不凭“3030”等口语规格推断兼容性。
3. 能说明简支梁等简化模型的前提，计算单根梁的挠度并识别连接、侧向晃动、倾覆等尚未覆盖的风险。
4. 能从设计生成切割清单、连接件清单、加工要求、装配顺序与询价表，区分估价和有效报价。
5. 能完成一个低风险作品的实物复核，记录设计值、实测值与返工原因。载人、吊挂、儿童攀爬等用途需另行做工程评估。

## 学习路径

| 篇次 | 问题 | 可交付练习 |
| --- | --- | --- |
| 01 | 铝型材 DIY 系统有哪些部分，力怎样传到地面？ | 为一个架子画尺寸草图和载荷路径 |
| 02 | 6063-T5、挤压截面、槽型和表面处理分别决定什么？ | 对比两个供应商的具体型材 SKU |
| 03 | 如何把需求变成几何尺寸、净空和切割长度？ | 画三视图与第一版切割表 |
| 04 | 梁的挠度、应力和安全裕量怎样估算？ | 用厂家截面数据做单梁计算 |
| 05 | 接头、角码、斜撑、面板怎样改变整体表现？ | 标出连接与侧向稳定方案 |
| 06 | 加工、装配公差、工具与实际装配如何衔接？ | 写加工说明和装配顺序 |
| 07 | BOM、报价、损耗和供应商兼容性怎样核对？ | 完成可询价 BOM 与成本区间 |
| 08 | 如何做一个小作品并用实测修正模型？ | 完成设计、询价、组装、复盘 |

篇次和练习会根据你的反馈调整。产品调研可作为第 07 篇的采购案例；其供应商工艺与价格应在实际下单时重新核对。

## 来源边界

- [80/20 University Booklet](https://catalogs.8020.net/data/uni19flx/011/html/export/80-20%20Inc.%20University%20Booklet.pdf)：简化梁模型、挠度和整件设计需考虑的载荷、倾覆等因素。
- [MISUMI Aluminum Extrusions Load Capacity Guideline](https://us.misumi-ec.com/pdf/fa/2010/p2433.pdf)：特定边界条件下的挠度表，不能当整件框架的承重认证。
- [嘉立创 FA 工艺参数](https://xc.jlcfa.com/process)：特定供应商的材料、切割和孔加工规则；不推广为所有厂家的统一规格。
