# 汇丰 Premier 跨境账户链路：状态机与核验点

这篇笔记把原文的线性步骤改写为状态机。这样能看到真正需要核验的条件，而不是只看到开户动作。

## 状态机

```text
S0 资料就绪
  └─ 身份、地址、税务居住地、开户目的和资金来源能如实证明
        ▼
S1 首个 HSBC 账户已开立
  └─ 账户可用 ≠ Premier 资格已生效
        ▼
S2 首个市场的 Premier 资格已书面确认
  └─ 确认资格标准、豁免费、有效范围与复核周期
        ▼
S3 HSBC US 审批完成
  └─ 单独满足美国开户、KYC、地址与税务要求
        ▼
S4 美国 Premier 资格持续有效
  └─ 确认 USD 100,000、合资格 Direct Deposit、按揭或 Private Bank 等适用路径
        ▼
S5 跨市场关联已完成
  └─ 各市场确认 Global View/主关系行和服务费处理结果
        ▼
S6 同名券商资金通道已可用
  └─ 核验入金、出金、换汇、费用、资金用途与限额
        ▼
S7 持续运营
  └─ 按月复核资格、费用、交易记录、税务申报与文件有效期
```

## 每一跳要留下什么证据

| 跳转 | 必要证据 |
| --- | --- |
| S0 → S1 | 银行接受的身份证明、住址证明、税务自证和真实开户用途 |
| S1 → S2 | 账户条款、费用表或客户经理的书面确认，不使用口头承诺 |
| S2 → S3 | International Services 的申请回执、补件要求和最终账户通知 |
| S3 → S4 | 美国账户的实际产品条款；特别是 Direct Deposit 的定义与已入账分类 |
| S4 → S5 | 每个市场对关联成功、服务资格和收费结果的独立确认 |
| S5 → S6 | 券商与银行各自允许的同名出入金路径及费用表 |
| S6 → S7 | 月度对账单、收费通知、资格状态、跨境收支材料与申报记录 |

## 当前公开信息带来的两个修正

HSBC US 目前公开列出的 Premier Checking 免月费路径包括：与 HSBC 的存款/投资总关系余额至少 100,000 美元、每月合资格 Direct Deposit 至少 5,000 美元、合资格美国住房贷款或 Private Bank 身份。[HSBC US Premier](https://www.us.hsbc.com/checking-accounts/products/premier/)

因此，“有一笔 5,000 美元 ACH 交易”与“满足合资格 Direct Deposit”不是同义句。必须让银行明确该笔交易在系统中的资格分类。
