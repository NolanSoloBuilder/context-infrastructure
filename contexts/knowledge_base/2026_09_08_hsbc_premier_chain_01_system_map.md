# 汇丰 Premier 跨境账户链路：系统地图

来源是用户提供的《开户圣经》。这篇笔记只解释它试图构造的系统，不把原文当作当前可执行 SOP。

## 一句话

这是一种把“某一个市场的 Premier 资格”当作全局身份凭证的账户关系设计：先建立一个可被 HSBC 跨市场识别的客户关系，再让美国账户承担资格状态与资金入口，最后将中国、香港和经纪商放入同一张资金网络。

```text
身份与文件一致性
        │
        ▼
HSBC CN 或 HSBC HK：首个可验证的 Premier 关系
        │  International Services / RM / KYC
        ▼
HSBC US Premier：资格状态、主关系行候选、美国本地收付节点
        │  Global View / Global Transfers / 跨市场关系核验
        ├──────────────► HSBC CN / HK：关联账户与当地服务资格
        │
        └──────────────► 券商：投资账户及同名资金通道
```

## 这张图里的四种不同对象

| 对象 | 系统职责 | 原文容易混淆的点 |
| --- | --- | --- |
| Premier 资格 | 服务费豁免、服务层级、跨市场支持的可能前提 | 它不是开户保证，也不自动等于所有市场的同一待遇 |
| 银行账户 | 收付、存款、卡片、KYC 与税务声明的载体 | 同属 HSBC 不等于可自由跨境或免手续费 |
| Global View / 主关系行 | 账户可见性与客户关系协调机制 | 关联不等于隐私隔离，也不替代每个市场的合规审查 |
| 券商账户 | 投资、换汇、出入金与持仓记录的载体 | 不能把券商转账当然视作工资型 Direct Deposit |

## 原文的关键依赖

1. 第一个 HSBC 市场愿意建立 Premier 客户关系。
2. HSBC US 愿意按申请人真实身份、居住地、开户目的和文件审批账户。
3. 美国账户的实际资格条件持续满足，且银行认可所用的入账类型。
4. 各市场愿意接受账户关联和服务资格的跨市场核验。
5. 每笔资金流均满足银行条款、外汇监管、反洗钱审查和税务申报义务。

只要其中一个条件不成立，后续节点都不能视为“自动继承”。
