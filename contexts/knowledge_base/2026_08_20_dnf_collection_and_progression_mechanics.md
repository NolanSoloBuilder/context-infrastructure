# DNF 式收集与养成机制术语

## 核心判断

玩家在 DNF 一类游戏中感受到的“收集、投入、变强、舍不得放下”，并非一个单独机制，而是几层设计共同作用：

- **收集系统（collection system）**：获得并保存装备、时装、宠物、称号、材料或图鉴条目。玩家追求“拥有”和“补齐”。
- **完成主义（completionism）**：玩家倾向于填满图鉴、集齐套装、补齐缺口。它描述玩家动机，不是系统本身。
- **角色成长系统（character progression）**：玩家投入时间和资源，让角色能力持续提高。中文游戏行业常称“数值养成”或“成长线”。
- **纵向成长（vertical progression）**：攻击、名望、强化等级等数值不断提高；区别于增加打法选择而不直接提高数值的横向成长（horizontal progression）。
- **多线养成 / 分层成长（layered progression）**：装备、强化、增幅、附魔、徽章、护石、宠物、称号等多条成长线并行叠加。
- **装备构筑（itemization / build crafting）**：装备不只是收藏物，还决定属性组合、技能流派和战斗方案。
- **战利品追逐（loot chase）**：为了更稀有、更完整或数值更高的掉落反复游玩内容。
- **装备跑步机（gear treadmill）**：取得当前装备后，更新的副本和装备又建立下一阶段目标，成长循环持续延长。这个词通常带有批判意味。

## 循环

这类游戏的核心成长循环通常是：

`游玩内容 → 获得装备和材料 → 强化角色 → 解锁或挑战更高难度内容 → 获得更好的装备和材料`

行业里可以称为 **core progression loop**；若突出刷取掉落，也可以称为 **loot loop**。

## 玩家为何会产生感情

投入本身会改变物品和角色在玩家心中的价值：

- **禀赋效应（endowment effect）**：已经拥有的东西会被赋予更高价值。
- **努力合理化（effort justification）**：投入越多，越倾向于认为成果有价值。
- **沉没成本效应（sunk cost effect）**：过去投入会提高离开的心理成本，即使继续投入未必划算。
- **目标梯度效应（goal-gradient effect）**：距离套装完成、强化目标或下一档名望越近，行动动力越强。
- **能力感（competence）**：数值、通关效率和可挑战内容的变化，让玩家持续获得“我掌握得更好了”的反馈。

因此，“看着角色慢慢成长”的准确说法是 **长期角色成长（long-term character progression）**；如果强调玩家与角色之间因为长期投入形成的情感，则可称为 **investment-driven attachment**，即“由投入形成的依恋”。

## 一句话概括

DNF 的典型体验是：以 **战利品追逐** 驱动 **收集系统**，通过 **多线数值养成** 形成长期的 **角色成长**，再由持续投入和阶段性完成感建立玩家依恋。

## 版本换代与装备保值

DNF 式版本更新通常属于 **周期性纵向重置（periodic vertical reset）** 或 **软重置（soft reset）**：角色、账号和部分打造继续保留，但当期核心装备会随等级、词条或副本门槛更新而失去主导地位。这也是装备跑步机的一部分。

可交易型老网游则更接近 **持久化物品经济（persistent item economy）** 或 **玩家驱动经济（player-driven economy）**。装备同时具有三类价值：

- 使用价值：穿戴后提高战斗能力。
- 交换价值：可以在玩家市场出售。
- 储值价值：只要供需和规则相对稳定，就可以暂时承载玩家财富。

DNF 的大部分阶段装备主要承担使用价值。版本更新让新装备成为新内容的奖励，旧装备需求随之下降；即使某些打造资源允许继承，具体装备本体仍可能退出主流。可自由交易的稀缺装备即使不再是绝对最强，也可能因为供给有限、制作成本、市场流动性和次级玩家需求而继续有价格。

### 两种设计目标

**阶段性装备体系**希望做到：

- 新版本上线后，所有活跃玩家重新进入同一套追逐循环。
- 新副本始终能发放有意义的新奖励。
- 控制长期数值膨胀，并给回流玩家重新追赶的窗口。
- 由策划掌握装备供给、成长节奏和商业化节点。

代价是玩家容易产生资产折旧感和重复劳动感。

**持久化交易体系**希望做到：

- 玩家长期积累能够形成财产感。
- 制造、掉落、交易和囤积形成社会分工。
- 玩家之间的市场本身成为长期玩法。

代价是老玩家优势容易固化，新玩家进入成本提高，并伴随通货膨胀、工作室、现实货币交易和市场操纵风险。设计者还需要通过交易税、耐久消耗、合成消耗等 **item sink（物品回收口）** 对冲持续产出的 **item faucet（物品投放口）**。

### 判断装备是否真正保值

不能只看游戏币标价是否不变，还要同时看：

- 相对于游戏货币购买力是否保值。
- 是否存在持续成交，而不仅是高价挂单。
- 新内容是否仍需要这件装备。
- 供给是否受到控制，装备是否会被绑定或回收。
- 官方是否承诺或长期实践较低的装备淘汰速度。

因此，两类游戏的差异可以概括为：前者把装备当作阶段性进度工具，后者允许部分装备成为可交易、可储值的持久资产。
