1、学习路线～0-3个月
熟练掌握 iOS 语言基础

四端不对称的关键点（务必建立认知）：

6、与后端学习计划的关键差异
客户端同学需要特别建立的四个认知，这些是后端岗位不会遇到的：
发布不可逆 —— 服务端可以秒级回滚，客户端发出去就收不回。分阶段发布只能暂停、不能撤回，因此任何有风险的功能都必须配服务端开关。
性能即体验 —— 后端看 QPS / RT / 可用性，客户端看崩溃率、帧率、内存峰值、包体积、启动耗时。这些要形成肌肉记忆。
内存与线程是高频事故源 —— 循环引用、KVO 未移除、多线程竞争，是客户端 Crash 的最大来源，也是 Code Review 的重点。
排查链路更长 —— 客户端问题依赖日志回捞 + trace 关联 + 用户复现，无法像服务端那样随时登机器看现场。要尽早熟悉全套排查工具链。
