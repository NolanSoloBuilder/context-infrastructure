## 归档方式与边界

- 根目录 Markdown 是 CLI 导出的原文，未改写内容；已有 sourcemap 一并保留。它不是服务端原生格式、评论和版本历史的完整备份。
- 122 个内联图片 URL 全部下载成功，按内容哈希存入 assets/；offline/ 仅将图片地址替换为本地路径，文字不改写。原图映射和校验值见 [图片清单](assets_manifest.json)。
- 历史自评保存浏览器实际读取的正文 .txt 和包含链接的 .dom.txt，包含页面当时可见的自评、主管评价及导航，不代表HR后台数据导出。
- 文档中的普通链接保留原地址；未递归抓取所有引用文档、视频或非图片附件。周报中非本期或非本人相关的内容保留原文，但不纳入本期成绩。
- [sources.json](sources.json) 提供按来源检索的机器索引；[manifest.json](manifest.json) 记录本目录文件 SHA-256；[校验脚本](verify_archive.py) 可检查缺失、修改和原文覆盖。
- 本地复盘稿、角色补充及核对笔记均为整理稿，与原始文档分开。
