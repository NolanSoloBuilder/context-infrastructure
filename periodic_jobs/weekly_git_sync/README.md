- 保留最终 Markdown、一份用于离线阅读的 `report.html`、正文引用的图表，以及复核关键判断所需的行情、估值、来源记录和清单。确保交付文件的相对引用及后续运行所需的基线能跨机器使用。休市沿用前一期数据时，优先引用原有效日期。
