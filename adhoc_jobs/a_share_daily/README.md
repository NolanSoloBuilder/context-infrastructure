# A股个人晨报

日报真源：`contexts/survey_sessions/a_share_daily/YYYY-MM-DD/report.md`。
个人观察合同：同目录上级的 `investor_profile.json`；星级提醒状态：`decision_state.json`。

## 生成HTML

```sh
python3 adhoc_jobs/a_share_daily/render_html.py contexts/survey_sessions/a_share_daily/YYYY-MM-DD/report.md
```

Python入口调用本目录 `render_html.mjs`。A股HTML直接复用相邻美股目录的 `report.css` 和 `report_interactions.js`，保持报刊式页眉、日期、置顶导航、四指数横栏、图表放大、详情折叠及打印行为一致；不要在A股另加一套hero、装饰卡片或独立CSS。美股文件只读取，不在本任务中修改。

首页依次展示今日判断、四指数横栏、最重要的1–3件事、主观察表与图、估值与图、个人入场研究。完整作者资料、触发规则、来源及事件默认折叠。行情、持仓、预算、观察阈值和交易建议各自独立，不能从美股报告复制到A股。

开头的今日判断需解释螺丝钉星级含义，注明当期整体星级、较上一有效期变化及与用户5星观察线的关系，并区分整体星级与单指数分类。估值主表纳入作者当期标为低估的全部品种，不限制为主观察ETF，也不能写死27行；与原图逐项核对后生成`valuation_cheap.json`。整理页阈值计算与原图/接口分类不一致时，保留作者分类并标注差异。指标与单位分别展示，不把全名单当作应买入的基金组合。

输出是单文件离线HTML；本地Markdown参考内嵌为折叠附录，本地证据内嵌为下载入口。`html_manifest.json`记录来源与共享样式哈希。

来源快捷链接须紧邻对应观点、数据行或图表，标签用“原文↗”“行情↗”“来源记录↓”等短语；优先具体原文而非通用主页。行情逐行链接实际接口，同源估值表在图表旁及折叠块开头集中链接原文与原图，避免27行重复链接。群内内容无核验过的消息链接时提供已筛选来源记录下载，不编造飞书深链；研究推论与用户确认信息不冒充作者原话。
