# A股个人晨报

日报真源：`contexts/survey_sessions/a_share_daily/YYYY-MM-DD/report.md`。
个人观察合同：同目录上级的 `investor_profile.json`；星级提醒状态：`decision_state.json`。

日更保留本地 HTML、发布与验收记录。后续同步 Git 时按[日报入库规则](../../periodic_jobs/weekly_git_sync/README.md#日报入库规则)选取最终报告、必要证据和发布凭证，核对次日沿用的行情和估值基线。

## 生成HTML

```sh
python3 adhoc_jobs/a_share_daily/render_html.py contexts/survey_sessions/a_share_daily/YYYY-MM-DD/report.md
```

Python入口调用本目录 `render_html.mjs`。A股HTML直接复用相邻美股目录的 `report.css` 和 `report_interactions.js`，保持报刊式页眉、日期、置顶导航、详情折叠及打印行为一致；A股适配及趋势卡片仅使用本目录report_mobile.css补丁，不另起一套装饰版式。美股文件只读取，不在本任务中修改。

首页依次展示今日判断（整体星级与个人动作）、合并主观察表、交互趋势图（含中概分组）、待确认资金条件。完整作者对照、触发规则、来源及事件默认折叠。取消重复指数横栏、单独估值主表、重复首页摘要和重复静态图展示。行情、持仓、预算、观察阈值和交易建议各自独立，不能从美股报告复制到A股。

开头的今日判断需解释螺丝钉星级含义，注明当期整体星级、较上一有效期变化及与用户5星观察线的关系，并区分整体星级与单指数分类。主表纳入作者当期常规原图的全部指数，保留低估/正常/高估三类，不限制为主观察ETF，也不能写死27行；与原图逐项核对后生成`valuation_cheap.json`。整理页阈值计算与原图/接口分类不一致时，保留作者分类并标注差异。指标与单位分别展示，不把全名单当作应买入的基金组合。

输出是单文件离线HTML；本地Markdown参考内嵌为折叠附录，本地证据内嵌为下载入口。`html_manifest.json`记录来源与共享样式哈希。
