# 小红书说明图视觉规格

## 全局视觉

- 比例：3:4 竖版。
- 风格：理性、克制的杂志编辑式信息图；浅暖灰纸张背景，细网格纹理。
- 主色：炭黑 `#171717`、暖白 `#F3F0E8`。
- 强调色：橙红 `#FF5A3C`、钴蓝 `#315CFF`。
- 字体感：现代中文无衬线粗体，标题大，说明文字少而清楚。
- 图形：人、角色卡片、群聊、仓库、文档和箭头采用扁平线性图标。
- 禁止：机器人头像、赛博霓虹、3D 玻璃球、拟人化 AI 大脑、无关英文、随机小字、水印。

## 01 封面

- 主标题：`每个人都有 AI`
- 第二行：`团队效率却没变`
- 小字：`AI 进入团队协作，才是下一步`
- 画面：四个团队成员各自被独立聊天框包围，底部有一条尚未连通的共享工作流；一个醒目的问号连接两行标题。
- 风格来源：xhs-cover 的 `thinking-question` 与 `multi-layer-layout`，改为无人物照片的信息图版本。

## 02 每个人都在变快

- 标题：`每个人都在和自己的 AI 协作`
- 标签：`产品`、`设计`、`前端`、`后端`
- 小字：`需求更快｜设计更快｜代码更快`
- 画面：四个角色分别面对四个隔离的聊天窗口，窗口之间没有连接。

## 03 团队 Context 仍然断开

- 标题：`个人变快了`
- 第二行：`团队 Context 还是断开的`
- 散落标签：`会议`、`群聊`、`设计稿`、`前端仓库`、`后端仓库`、`历史决策`
- 画面：六个信息孤岛，中央缺少共同连接点。

## 04 下一阶段

- 标题：`AI 开始进入团队协作`
- 左侧标签：`每个人与自己的 AI`
- 右侧标签：`团队与共享 Agent`
- 画面：左边四条私有连线；右边四个人共同连接产品、设计、前端、后端四个职责 Agent。

## 05 Shared Agent Workspace

- 标题：`同一个 Workspace，共用一组职责 Agent`
- 中央：`Workspace Context`
- 上方节点：`产品 Agent`、`设计 Agent`、`前端 Agent`、`后端 Agent`
- 下方来源：`会议`、`群聊`、`产品文档`、`设计稿`、`前端仓库`、`后端仓库`
- 小字：`按职责、权限和当前任务动态调用`

## 06 从讨论到交付

- 标题：`会议结束，工作才真正开始`
- 流程：`会议 / 群聊` → `候选工作项` → `人确认` → `Agent 执行` → `测试 / Review` → `写回 Workspace`
- 小字：`讨论、执行、产物和证据在同一条链路里`

## 07 结尾

- 主标题：`AI 的下一步`
- 第二行：`从个人助手，变成团队基础设施`
- 提问：`你的团队会共用 Agent 吗？`
- 画面：原本分散的四个聊天窗口汇入一个安静、清晰的共享工作空间。
