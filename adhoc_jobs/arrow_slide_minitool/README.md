# 箭头画谜

小红书小工具名称建议「箭头画谜」，一句话简介「按顺序解开箭头」。发布包是 `publish/arrow_slide_minitool.zip`，图标与封面在同一目录。包根入口为 `index.html`，四个文件均可离线加载。

## 复刻依据

- [CrazyGames 原作](https://www.crazygames.com/game/arrow-slide-puzzle) 公布了清除箭头揭图、提示、拖动和三种缩放入口。REA 在该页确认了实际游戏 iframe，并在发布者游戏端捕获了教学棋盘和箭头滑出动画。
- 核对了原作公开下发的 JavaScript 包 `game-v1.514.2-41d0d39308.js`。全包 REA 语义分析达到单文件时限，之后对箭头、机会计数和单局控制的原始字节片段完成定向分析。
- 位于同一格线的折线箭头整体沿头部方向滑出。头部射线受阻时，箭头沿自身路径向前再退回。连续点同一支受阻箭头只扣一次。提示选一支可出场箭头，磁铁同时移走最多三支可出场箭头，橡皮按视口中心的曼哈顿距离移走最近三支。
- REA 证据 ID：教学 `ev_4f7db5c05c9279a2e98556c74b91fb2fe956a55034d76cf83970f8126a850043`，滑出 `ev_3c98699bf37420268ebf54b827acf543a5ce3862c0b03579ae3d8eeaa340608d`，定向分析 `ev_40057930d2f9edfc01a321e2d3d77d07ef734de1767b749d5a4ef438540847fe`。原作后续运行进入转场加载，完整流程按发布包行为与可见画面对齐。

## 小工具实现

独立实现 120 关、教学关、三次失误、失败重开、下一关、三种离线道具、声效、手势及滑杆缩放。关卡布局由固定种子生成。从解题顺序逆向放置路径，每次放入一支能直接滑出的箭头，因此存在逆序解。存档使用小红书公开 Storage API，低版本或接口不可用时可在当前会话继续玩。依据[小工具容器文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)检查资源规则、安全区及振动接口。

离线版采用自制页面、棋盘、画面和音效。道具补给采用每局固定库存，原作的广告、购买、账号、活动和运营后端需要各自的平台实现。本 ZIP 由独立实现的静态文件构成。

## 手机参考后的棋盘调整

第 1 关采用三支平行直箭头。第 2 关采用三支折线，玩家需要依次清除相互遮挡的路径。第 3 关开始用 20×31 或更大的纵向网格，长折线和短箭头交错排布。第 3 关共有 40 支箭头，占据 620 格中的 515 格。盘面更新后，旧存档保留当前关卡编号，进入当前关时从新盘面开始。

新版 120 关全部通过逐关求解。已在小红书 iPhone 预览核对前三关的布局和转场。

图标与封面可用 `NODE_PATH="$(npm root -g)" node design/render_assets.cjs` 重新生成，生成脚本使用全局的 `@napi-rs/canvas`。
