# 串串小铺

从用户连接的 OPPO 安卓设备上安装的 `com.ig.skewer.jam.food.sort` 提取资源，重建为纯离线的小红书小工具。2026-11-18 制作；已生成手机预览并提交1.0.4审核；当前审核中，尚未正式发布。

## 运行与交付

```sh
pnpm --filter @xhs-minitools/skewer-jam test
pnpm --filter @xhs-minitools/skewer-jam dev
pnpm --filter @xhs-minitools/skewer-jam package
```

ZIP 在仓库根目录 `artifacts/skewer-jam.zip`。`src/index.html` 为唯一入口，使用经典脚本、ES2017、Chrome 61 可用布局，无外网请求、内联脚本、WASM 或第三方运行时。开发时使用 redapp 官方本地模拟器。

## 已实现

- 点击烤盘上的食物；匹配的串串自动进入订单，每盘 3 串。
- 5 个暂存位，满盘失败；订单更新时，暂存食物按真实结算顺序逐串飞入新餐盘。
- 清空一个烤盘后展示下一盘，界面预览下一盘食材。
- 第二关起可点绿色加号增加订单餐盘，最多 4 个。
- 60 关：首关教学 9 串、4 个步骤，第二关 54 串，后续逐步增加食物种类和叠盘。
- 第 3/5/7/10 关分别解锁加暂存位、重排、自动上菜、更换订单。按标价花金币购买并使用，保留原有局面次数限制；没有广告依赖或强制关注。
- 教学依次覆盖凑三串、揭开下一层、暂存、自动补单；只引导当前步骤，提示按钮同步当前教学目标。兼容旧版 6 串首关存档。
- 首次教学完成显示可跳过的关注提示，查询关系后决定是否显示关注按钮；平台关注需用户点击后再确认，取消/失败/限流不阻断继续游戏，重复教学不再弹。关注 API 版本为 9.51+，低版本提示从作者主页关注。依据：[官方关注作者文档](https://miniapp-sandbox.xiaohongshu.com/minitool/doc)。
- 撤销最近 30 步、提示、失败救援、重开、选关、通关解锁；快速输入排队执行，并避免重复取串或跨层误取。
- 40 种从原包提取的食材；第二关保留观察到的组合，后续关卡使用确定性食材组合。
- 订单待上菜食材按用户指定为 65% 不透明度，已上菜保持 100% 与落盘投影。
- 樱花木盘、日式红盘、中式小铺三种主题；使用原版锁头、底座、手势和星光，包含取串、落盘回弹、清盘退场、补盘展开与进度动画。
- 换关前准备所需素材，当前会话保留稳定的解码图片引用；失败保留当前关卡并支持重试。
- 平台 Storage 优先的存档；低版本才尝试浏览器存储。读取平台存档失败时不覆盖未知旧数据；写失败明确提示。
- 获取容器窗口信息，避让顶部胶囊并处理安全区；后台暂停音频。

## 素材与音频

`ASSET_PROVENANCE.json` 记录 APK SHA-256、原始 AssetBundle / Sprite 名称、path ID 和素材哈希。素材来自该设备上的安装包，不是新生成的替代图；本次没有确认这些第三方素材的公开再发布许可。

导出了 33 段原版 WAV；包内选用完整约 66.2 秒背景音乐及 10 种交互音效，保留失败、通关和道具音效的完整尾音。音效编码为 44.1 kHz / 96 kbps 单声道 MPEG，音乐为 24 kHz / 64 kbps；不再使用 6/8 kHz 8-bit PCM。受文件类型白名单限制，以明确标注 codec 的字节数组存放于 `assets/audio-effects.js` / `audio-music.js`，Web Audio 本地解码，不伪装媒体后缀、使用媒体 data URL 或联网。两组源码分别约 659 / 1835 KiB；解码后删除原始数组，缓存 AudioBuffer。

`audio.js` 负责预解码、手势解锁、分事件音量、限幅压缩、最多 8 个音效声部及后台停止。主输出增益为 0.9，起点扫描只在解码时执行；队列接收点击立即给取串反馈。完成/通关时音乐从 0.12 降到 0.025 后渐回，连续触发保持包络连续；效果限幅和音乐独立，缓存效果同步触发且不按主线程墙钟丢弃。取串→310ms 飞行→入盘/暂存→完成餐盘各有对应原版声音；通关音在最后一盘完成后 260ms 触发。客户端 9.50+ 才调用平台振动：取串轻短震、道具中短震、完成盘重短震、通关长震（无长震方法则重短震）。实际强度与持续时间由设备决定，不支持自定义波形。

原版音效来源已确认；事件音量、混音、震动强度和 Web 动画是本实现调校，尚未通过原版设备音轨录制逐帧验证。

## 本轮性能与动画

烤盘使用食材层的短状态签名比较，只更新变化烤盘，复用其他串串节点；飞行只更新 transform，去掉逐帧 filter。粒子并发上限20，普通落盘2、完成8、胜利18；非当前关食材改为空闲时逐个预热，页面隐藏时暂停预热。

订单完成约380ms渐隐，清空烤盒约360ms渐隐到已售罄底板，新订单延后200ms进入；减少动态效果设置下跳过飞行、粒子和退场快照。以上为实现预算，未测得真实低端机帧率。

离线 DOM 集成检查（不等于模拟器、浏览器或真机验收）：`npm install -g linkedom` 后运行 `pnpm --filter @xhs-minitools/skewer-jam test:ui`。依赖仅安装到全局开发环境，不进代码包。该检查完整走教学两遍、关注按钮 mock 确认、跳过、存档防重复及烤盘节点复用。


## 通关路径提示

普通关提示从完整当前状态搜索，使用与实际游戏相同的 `pick` / `addOrder` 结算逻辑；仅输出一条已搜到完整通关路径的首步，必要时明确提示先点绿色加号增加免费订单，不自动操作或花道具。后续按同一条已证明路径继续时使用坐标敏感的状态缓存，玩家偏离、揭层、用道具或撤销后按新局面重算。教学关继续采用已完整回放验证的四步引导路线。

搜索分片目标每片最多6ms/128次分支，最多50000个转移、20000个失败状态，UI总预算4秒；性能数值是实现预算而非真机帧率。穷尽候选后才报告“仅取串和加订单不可解”；预算耗尽返回“未找到可靠路径”，不冒充无解、不输出猜测。搜索期间可继续取串，状态改变或页面隐藏会取消旧任务；高亮采用常驻绿框与“点这里”标签，持续到下一次操作/取消，不依赖动态效果；计算中和找到解都有文字反馈。求解不把付费/有限次数道具、撤销操作当作隐式后续步骤。


## 金币

初始60；教学首通+40、普通首通+50；每个普通关首次重玩+10，再次重玩不再奖励。提示25、撤销10、加格30、重排20、换单30、自动上菜50。教学提示/撤销免费，同一已购买局面再看提示免费；只有显示可靠提示才扣费，道具成功生效才扣费。钱包不随撤销/重开回退，关卡奖励按持久化局次去重。金币不足仍可免费重开、取串和加订单。详细取舍见 `DECISIONS.md`。底部显示余额和标价，结算显示本次收入。旧进度首次迁移发放60，不补发旧首通收入。

## 本轮性能优化

订单和暂存改为按卡片/格位更新，装盘仅切换filled状态，复用解码图片与未变节点；工具文字、主题与网格布局避免重复赋值。存档保留加密/版本/失败保护，将待发请求合并为最新完整快照，去掉app侧重复JSON复制；下一关最多预热3种缺失食材，保留现有素材画质。动画只在确需重启时读取offsetWidth，提示搜索复用同一棋盘签名和已计算状态键。

同一离线DOM流程订单/暂存图片节点504→89；受控慢存储测试10次保存请求→2次实际写。44项逻辑测试、8条离线DOM流程通过。这里测量的是节点创建和受控写入次数，没有测量真机帧率。


### 前后台音频恢复

音频单独处理 `interrupted` / `suspended` 恢复，等待 resume 确认后启动音乐；后台停止声音，pageshow/focus 与触摸手势触发恢复。快速往返时，延迟的 suspend 回执会按当前可见状态恢复；过期恢复回执不重新播放旧音效。能力可用时选择 playback 音频会话，保留静音与弹窗暂停设置。对应测试见 `tests/audio.test.cjs`，真机前后台恢复需扫码验证。
