# Scratchpad

日期：2026-08-20

## 初始问题

- 四类居住状态是否对应不同的家装游戏偏好？
- 豪宅补偿、小家成长、设计师委托、纯沙盒分别满足什么心理需要？
- 现实空间缺少控制是否会转化为虚拟空间中的心理所有权和留存？
- 产品怎样避免把现实匮乏重新做成体力、抽卡和限次家具？

## 探索性观察

- 纯沙盒有明确用户，但需要强编辑器和较高创造自我效能。
- 空白画布和选择过载同样是真实痛点，适度约束可作为创作脚手架。
- 国内装修用户常被三消、广告、抽卡、多货币与小游戏打断。
- 角色/宠物使用家具、昼夜变化、物件记忆比静态效果图更能形成“家”。
- 共享装修牵涉控制、责任、领地和删除权限，不适合首版直接做实时共编。
- 最可能结构：永久自己的小家为情绪中心，客户委托提供能力感和灵感，纯沙盒作为随时可进入的表达层。

## 证据边界

- 社群帖子只能发现模式和语言，不能代表总体比例。
- 居住状态与游戏偏好之间目前无直接因果证据。
- “逃避现实”包含自我扩展与自我压抑两种路径，不能直接宣称改善心理健康。
