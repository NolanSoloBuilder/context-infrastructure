## 初步产品判断

1. 首个传播型 MVP：关系人格 / 关系安全感 / 双人匹配。
2. 长期主品牌：原创“十大优势画像”，强调个人说明书而非权威天赋诊断。
3. 科学底座：IPIP Big Five 或 O*NET RIASEC；娱乐表达层可借鉴 SBTI，但不混用“科学测评”标识。
4. 结果页的核心不是雷达图本身，而是可认领的组合名、场景解释、盲点和下一步动作。

### 更新后的产品判断

1. 首发：`恋爱心理测试` 作为入口，`恋爱使用说明书` 作为结果。
2. 漏斗：5–7 道趣味情境题负责低门槛传播；18–24 道深度题负责维度结果和双人匹配。
3. 长期模型：原创优势维度仍值得做，但藏在报告底层，不把“十大天赋”作为获客标题。
4. 内容获客：隐藏人格 / 动物塑 / 文学人格可以做独立轻测试，导流至深度关系或职业报告。
5. SBTI：近 7 天标题明确相关样本阅读中位数约 2484，保留为传播机制案例，不再视为当前新品类机会。

## 用户目标校准：利他型知识增长

- 核心目标：先用知识解决一个真实问题，再让测试帮助用户把知识应用到自己身上。
- 测试定位：自我观察工具，不是点击诱饵，也不制造“你有问题”的焦虑。
- 分享动机：结果卡应帮助朋友或伴侣理解用户，降低沟通成本，而不只是展示人格标签。
- 关注动机：持续提供不同关系模式的解释、组合案例、表达模板与练习。
- 增长链路：知识获得感 → 自我识别 → 完成测试 → 晒说明书 → 他人受益并进入测试 → 关注后续指南。
- 产品命名继续采用“恋爱使用说明书”；公开结果至少包含最看重的事、受伤时反应、有效沟通方式、容易被误解之处和正在练习的动作。
