# Search Manifest

日期：2026-07-23

本次因并行子代理与当前会话约束冲突，由主线程完成公开 Web、官方文档、竞品实测和项目只读数据核验；未生成子代理原始输出。

| 维度 | 入口/关键词 | 结果 |
|---|---|---|
| 爆款机制 | 跳一跳 留存 微信公开课 | 新榜转述官方数据：次留 65%、七留 52%；微信原生入口是关键背景 |
| 爆款机制 | 羊了个羊 DAU 启动次数 社交榜 | 月狐：2022-09-15 DAU 破亿；抖音起量、微信发酵、地区榜/阵营挑战/高难度驱动重复 |
| 抽象内容 | 电子木鱼 抖音 播放 下载 | 单动作、声音、荒诞隐喻能传播，但媒体同时指出生命周期风险 |
| 平台规则 | 抖音开放平台 小游戏 内容运营 视频锚点 | 官方支持游戏内容、UGC、榜单和留存运营；锚点需要平台小游戏能力与合规接入 |
| 通勤场景 | 城市通勤报告 短视频用户时长 | 证明注意力池和通勤碎片时间存在；未证明“假装忙”心理 |
| 怀旧钩子 | 金山打字游戏 2003 机房 回忆 | 怀旧认知存在，公开视频规模一般，适合副钩子 |
| 同类竞品 | metro typing / 地铁打字 / subway typing | 深圳中文竞品、首尔、日本等多款同构产品；类别成立，独特性下降 |
| 竞品实测 | https://typing.lemonation.cloud/ | 17 城、60 秒、1v1、排行榜、纠错；北京本周自由榜 6 人 |
| 项目核验 | README、ResultScreen、App URL、代码搜索 | 48 城/351 线；无线路深链、分享卡和前端漏斗埋点 |
| 仓库数据 | GitHub traffic views/clones | 14 天 19 views/10 uniques；clone 主要是开发行为，不可解释为玩家需求 |
