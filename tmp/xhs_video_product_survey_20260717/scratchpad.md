# 小红书视频下载与转写产品调研 Scratchpad

## 目标

判断视频下载能力是否值得做成对外收费产品，核对竞品、GitHub 可复用能力、技术与合规边界，并设计可以明显超越现有体验的产品切口。

## Phase 1 实测

测试链接：用户提供的公开小红书视频笔记。长期记录中不保存临时 `xsec_token`。

### AnyToCopy

- 页面定位：小红书文案提取、无水印视频、Live 图、图片、音频、批量 ZIP、API。
- 点击开始提取后立即弹出登录框，未登录无法看到解析结果。
- 首页声称支持 50+ 平台；登录后保留历史；图片解析免费不限量；视频文案每月有免费转录时长。
- 页面：<https://www.anytocopy.com/xiaohongshu>

### KuKuTool

- 无登录解析成功，约 2.5 秒出现结果。
- 测试结果提供普通视频 74.4 MB、超高清 1559.9 MB、音频提取、单项下载、批量 ZIP、复制媒体链接。
- 页面有明显广告；FAQ 明确称广告用于维持免费服务。
- 首页称支持 130+ 平台，登录后可免验证码；失败时推荐 App。
- 页面：<https://dy.kukutool.com/xiaohongshu>

## Claim Extraction

| Claim | 来源层级 | 验证通道 | 状态 |
|---|---|---|---|
| AnyToCopy 是下载、转写和 API 的付费产品 | Tier 1 官网 | 价格页、API 文档、真实登录前流程 | 已验证；API 未付费调用 |
| KuKuTool 主要靠广告维持免费解析 | Tier 1 FAQ + 页面实测 | 产品矩阵、批量入口 | 已验证 |
| 单链接下载已经高度同质化，难以单独收费 | 多个竞品实测与 API 定价 | KuKuTool、DouSnap、xiaohongshu.day | 已验证为强市场信号 |
| GitHub 已有成熟小红书下载内核可复用 | GitHub 仓库与许可证 | README、LICENSE、commits、issues、release | 已验证；需按许可证分层复用 |
| 本地浏览器执行比服务器代抓更稳定且隐私风险更低 | Chrome 官方 API、开源实现 | 平台条款、Chrome 商店政策 | 部分验证；不能消除平台风险 |
| 可收费价值更可能来自批量任务、可靠 API、转写与内容工作流 | 竞品定价与产品合同 | MediaClaw、AnyToCopy、长视频实测 | 已验证为产品假设，仍需用户付费实验 |

## 待合成维度

1. 免费单条解析器已经做到什么程度。
2. 付费用户是谁、为什么付费、持续使用频率如何。

5. 可被验证的差异化体验与最小收费产品。
